# 4.1. Инкапсуляция: Лучшие практики

Инкапсуляция — это не просто `private` поля. Это искусство проектирования "черных ящиков".

---

## 1. Принцип "Tell, Don't Ask" (Рассказывай, а не спрашивай)

**Плохо:**
Ты берешь данные из объекта, сам их считаешь и кладешь обратно.
```csharp
if (player.Health < 10) player.Health += 50; 
```

**Хорошо:**
Ты просто просишь объект сделать действие. Объект сам знает, как менять свое здоровье.
```csharp
player.Heal(50);
```

---

## 2. Не возвращай лишнего

Если у твоего класса есть список, не возвращай его целиком через `public List<Item> Items`. Кто-то снаружи может его очистить или добавить мусор. 
Возвращай `ReadOnlyCollection` или `IEnumerable`.

---

## 3. Защита состояния

Объект всегда должен быть в "валидном" (правильном) состоянии. 
Конструктор и свойства — это твои охранники. 
Если у тебя есть `Order` (Заказ), у него не может быть 0 товаров. Запрети это в конструкторе!
