## Объяснение

### ЗАЧЕМ?
**Аналогия:** Банкомат не даёт доступ к деньгам напрямую. Ты используешь интерфейс (экран, кнопки). Банкомат САМИ проверяет баланс, PIN, лимиты. Так и класс: данные приватные, доступ через свойства с валидацией.

```csharp
// ❌ ПЛОХО: публичные поля — любой может сломать
class BadPlayer
{
    public int Health = 100;
}
var p = new BadPlayer();
p.Health = -999; // Никакой защиты!

// ✅ ХОРОШО: инкапсуляция
class GoodPlayer
{
    private int _health = 100;

    public int Health
    {
        get => _health;
        set => _health = Math.Clamp(value, 0, MaxHealth); // 0-100
    }

    public int MaxHealth { get; init; } = 100;
    public bool IsAlive => Health > 0;
}
```

### Иммутабельность

```csharp
// Иммутабельный класс — после создания нельзя изменить
class Point
{
    public int X { get; }
    public int Y { get; }

    public Point(int x, int y) { X = x; Y = y; }

    // "Изменение" создаёт новый объект
    public Point WithX(int x) => new Point(x, Y);
}

var p1 = new Point(1, 2);
var p2 = p1.WithX(10); // p1 не изменился! p2 = (10, 2)
```
