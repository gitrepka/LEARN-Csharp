# 3.2. Интерфейсы: Суперспособности

Интерфейс (`interface`) — это еще более высокий уровень абстракции. 
Если класс — это "Кто я?", то интерфейс — это "Что я умею?".

---

## 1. Зачем нужны интерфейсы?

В C# нельзя наследоваться от двух классов. Но можно реализовывать **много** интерфейсов.

Представь:
*   У тебя есть класс `Bird` (Птица). Она умеет летать.
*   У тебя есть класс `Plane` (Самолет). Он тоже умеет летать.
Они совершенно разные, у них нет общего родителя. Но они оба реализуют интерфейс `IFlyable`.

```csharp
interface IFlyable
{
    void Fly(); // В интерфейсах методы по умолчанию публичные и абстрактные
}

class Bird : IFlyable
{
    public void Fly() => Console.WriteLine("Птица машет крыльями");
}

class Plane : IFlyable
{
    public void Fly() => Console.WriteLine("Самолет включает двигатели");
}
```

---

## 2. Интерфейс как контракт

Интерфейс гарантирует, что у объекта будет определенный метод. Тебе не важно, КТО это, тебе важно, что он УМЕЕТ.

```csharp
// Метод принимает ЛЮБОЙ объект, который умеет летать
void MakeItFly(IFlyable thing)
{
    thing.Fly();
}
```

---

## 3. Стандартные интерфейсы C#
Их тысячи. Самые важные:
*   `IDisposable` — для очистки памяти.
*   `IEnumerable` — чтобы объект можно было перебирать в `foreach`.
*   `IComparable` — чтобы объекты можно было сортировать.

## 5. Резюме
*   Интерфейс — это набор умений.
*   Начинается на букву `I` (по стандарту): `IWalkable`, `ISavable`.
*   Один класс может иметь много интерфейсов.
