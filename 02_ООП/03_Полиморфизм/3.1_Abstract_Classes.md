# 3.1. Абстрактные классы: Идеи без воплощения

Бывают классы, которые описывают слишком общее понятие. Например, "Животное" или "Фигура".
Существует ли в мире "просто животное"? Нет. Существует кот, собака, слон.
"Животное" — это **абстракция**.

---

## 1. Что такое abstract класс?

Это класс, от которого **нельзя** создать объект через `new`. Он нужен только для того, чтобы от него наследовались.

```csharp
abstract class Shape
{
    public string Name { get; set; }

    // Абстрактный метод: у него НЕТ тела. 
    // Это приказ всем наследникам: "Вы ОБЯЗАНЫ реализовать это!"
    public abstract double GetArea();

    public void PrintInfo() => Console.WriteLine($"Это {Name}");
}
```

---

## 2. Реализация в наследниках

```csharp
class Square : Shape
{
    public double Side { get; set; }
    
    // Мы обязаны переопределить GetArea
    public override double GetArea() => Side * Side;
}
```

---

## 3. Зачем это нужно?
Абстрактный класс — это жесткий контракт. Он гарантирует, что любая фигура (круг, квадрат, треугольник) будет иметь метод `GetArea()`.

---

## 5. Резюме
*   `abstract` класс — только для наследников.
*   `abstract` метод — приказ наследнику: "Сделай по-своему!".
*   Это позволяет строить фундамент для сложных систем.
