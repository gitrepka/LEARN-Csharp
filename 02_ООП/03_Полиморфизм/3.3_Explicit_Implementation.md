# 3.3. Явная реализация интерфейсов

Редкая, но очень важная ситуация: что делать, если класс реализует два интерфейса, у которых методы называются одинаково?

---

## 1. Пример конфликта

```csharp
interface IPlayer { void Play(); } // Играть в игру
interface IMusic { void Play(); } // Играть музыку

class Smartphone : IPlayer, IMusic
{
    // Как понять, какую Play мы реализуем?
}
```

## 2. Явная реализация (Explicit Implementation)

Мы указываем имя интерфейса перед именем метода. В этом случае `public` писать нельзя.

```csharp
class Smartphone : IPlayer, IMusic
{
    void IPlayer.Play() => Console.WriteLine("Запуск игры...");
    
    void IMusic.Play() => Console.WriteLine("Запуск музыки...");
}
```

### Как это вызвать?
Ты не сможешь вызвать `phone.Play()`. Тебе нужно сначала "превратить" телефон в нужный интерфейс.

```csharp
Smartphone phone = new Smartphone();

((IPlayer)phone).Play(); // Вызовет игру
((IMusic)phone).Play();  // Вызовет музыку
```

---

## 3. Зачем еще это нужно?

Чтобы "спрятать" технические методы. Если ты не хочешь, чтобы пользователь класса видел метод `IDisposable.Dispose()` напрямую, ты реализуешь его явно. Тогда он будет доступен только если явно привести объект к интерфейсу.

---

## 4. Резюме
*   Явная реализация — через `Interface.Method`.
*   Помогает избежать конфликтов имен.
*   Скрывает методы из общего списка (IntelliSense).
