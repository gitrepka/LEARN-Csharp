# 1.1. Классы и Объекты: Основы

До этого момента наш код был набором команд. ООП (Объектно-Ориентированное Программирование) позволяет нам моделировать реальный мир.

---

## 1. Что это такое?

*   **Класс** — это чертеж (шаблон). Например, чертеж Машины. Он описывает, что у машины есть (цвет, скорость) и что она умеет (ехать, тормозить).
*   **Объект (Экземпляр)** — это реальная машина, построенная по чертежу. У одной цвет красный, у другой белый.

---

## 2. Создание класса

```csharp
// Это чертеж
class Player
{
    // Поля (что у него есть)
    public string Name;
    public int Health;

    // Методы (что он умеет)
    public void TakeDamage(int damage)
    {
        Health -= damage;
        Console.WriteLine($"{Name} получил {damage} урона. Осталось HP: {Health}");
    }
}
```

---

## 3. Создание объекта (new)

Чтобы создать объект из класса, используется ключевое слово `new`.

```csharp
// Создаем первого игрока
Player p1 = new Player();
p1.Name = "Alex";
p1.Health = 100;

// Создаем второго игрока
Player p2 = new Player();
p2.Name = "Bob";
p2.Health = 80;

p1.TakeDamage(20); // Сработает только для Alex
```

---

## 4. Ключевое слово this

`this` — это ссылка на "самого себя". Она нужна, если имя параметра совпадает с именем поля.

```csharp
class Player
{
    public string name;

    public void SetName(string name)
    {
        this.name = name; // this.name - это поле класса, name - это параметр метода.
    }
}
```
