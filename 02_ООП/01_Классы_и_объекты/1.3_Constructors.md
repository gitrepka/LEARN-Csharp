# 1.3. Конструкторы: Рождение объекта

Конструктор — это специальный метод, который вызывается **автоматически** в момент создания объекта (`new`).

---

## 1. Зачем они нужны?

Чтобы объект не рождался "пустым" или "сломанным". Конструктор гарантирует, что у игрока будет имя и здоровье сразу при появлении.

```csharp
class Player
{
    public string Name;
    public int Health;

    // Имя конструктора совпадает с именем класса
    // У него НЕТ типа возврата (даже void)
    public Player(string name, int health)
    {
        Name = name;
        Health = health;
    }
}

// Использование:
Player p = new Player("Alex", 100); 
```

---

## 2. Перегрузка конструкторов

Их может быть несколько!

```csharp
class Player
{
    public Player(string name) : this(name, 100) // Вызывает другой свой конструктор
    {
    }

    public Player(string name, int health)
    {
        Name = name;
        Health = health;
    }
}
```

---

## 3. Primary Constructors (C# 12) — 🚀

Самый современный и короткий способ. Мы пишем параметры прямо у имени класса.

```csharp
class Player(string name, int health)
{
    public string Name { get; set; } = name;
    public int Health { get; set; } = health;
}
```

---

## 5. Резюме
*   Конструктор — это "входные ворота" объекта.
*   `this()` — позволяет одному конструктору вызывать другой.
*   `Primary Constructor` — экономит кучу кода.
