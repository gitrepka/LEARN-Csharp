# 1.4. Модификаторы доступа

В C# есть 6 уровней доступа, но в 99% случаев ты будешь использовать эти 4.

---

## 1. public (Публичный)
Доступен **всем и отовсюду**. Из других классов, из других файлов, из других библиотек.
*   *Когда:* Для методов и свойств, которые являются "лицом" твоего класса.

## 2. private (Приватный)
Доступен **только внутри этого класса**.
*   *Когда:* **ВСЕГДА** для полей. Для вспомогательных методов, которые не нужны снаружи.
*   *Если не указать модификатор, в классе всё по умолчанию private.*

## 3. internal (Внутренний)
Доступен везде внутри **твоего проекта** (сборки / .dll), но не виден снаружи (например, если кто-то скачает твою библиотеку).

## 4. protected (Защищенный)
Доступен в этом классе **и во всех его наследниках** (детях). Об этом подробно в следующем модуле "Наследование".

---

## 5. Зачем это нужно? (Инкапсуляция)

Представь пульт от телевизора.
*   **Public:** Кнопки. Ты можешь на них нажимать.
*   **Private:** Микросхемы внутри. Тебе не нужно (и опасно!) трогать их напрямую, чтобы переключить канал.

Если ты сделаешь всё `public`, другой программист (или ты сам) может случайно сломать внутреннюю логику твоего класса. 
**Правило:** Скрывай всё, что можно скрыть. Открывай только самое необходимое.
