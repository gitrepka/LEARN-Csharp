# 2.3. Sealed: Запрет на детей

Иногда ты хочешь, чтобы твой класс был финальным. Ты не хочешь, чтобы кто-то наследовался от него и менял логику.

---

## 1. sealed классы

Если пометить класс словом `sealed`, от него нельзя будет наследоваться.

```csharp
sealed class SecurityManager
{
    // Никто не сможет создать SecurityManagerPro и взломать логику
}

// class HackerManager : SecurityManager { } // ОШИБКА КОМПИЛЯЦИИ
```

### Зачем это нужно?
1. **Безопасность:** Чтобы никто не переопределил важную логику.
2. **Скорость:** Компилятор C# обожает `sealed` классы. Поскольку он точно знает, что наследников не будет, он может оптимизировать вызов методов (делает их быстрее).

---

## 2. sealed методы

Можно запретить переопределение конкретного метода, даже если класс не sealed.

```csharp
class Parent
{
    public virtual void Info() { ... }
}

class Child : Parent
{
    // Я переопределил метод и запрещаю своим детям менять его снова
    public sealed override void Info() { ... }
}
```

## 4. Резюме
*   `sealed` — конец цепочки наследования.
*   Это безопасно и быстро.
*   Используй, когда архитектура класса завершена.
