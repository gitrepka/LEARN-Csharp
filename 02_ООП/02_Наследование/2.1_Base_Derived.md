# 2.1. Наследование: База и Наследники

Наследование позволяет создать новый класс на основе уже существующего. Это способ сказать: "Класс Б — это разновидность класса А".

---

## 1. Зачем это нужно?

Представь игру. У тебя есть `Zombie`, `Skeleton` и `Orc`.
Все они умеют получать урон, у всех есть имя и здоровье.
Вместо того чтобы писать этот код 3 раза, мы создаем одного "Родителя".

```csharp
class Enemy
{
    public string Name { get; set; }
    public int Health { get; set; }

    public void Move() => Console.WriteLine($"{Name} движется к тебе!");
}
```

## 2. Ключевое слово : (Наследование)

```csharp
// Zombie наследует ВСЁ от Enemy
class Zombie : Enemy
{
    public void Bite() => Console.WriteLine("Зомби кусает!");
}

// Теперь у Zombie есть и Name, и Health, и Move()!
Zombie z = new Zombie();
z.Name = "Борис";
z.Move();
z.Bite();
```

---

## 3. Ключевое слово base

Если у родителя есть конструктор, наследник обязан его вызвать.

```csharp
class Enemy
{
    public Enemy(string name) { ... }
}

class Zombie : Enemy
{
    // : base() вызывает конструктор родителя
    public Zombie(string name) : base(name)
    {
    }
}
```

---

## 4. Ограничения

1. **Только один родитель.** В C# нельзя наследоваться от двух классов (например, `class Cyborg : Robot, Human` — ОШИБКА). Это сделано, чтобы избежать путаницы.
2. **Все классы наследуются от `object`.** Даже если ты ничего не написал, твой класс неявно наследует методы `ToString()`, `Equals()` и `GetHashCode()`.

## 6. Резюме
*   `:` — наследование.
*   Наследник получает все `public` и `protected` члены родителя.
*   `base` — обращение к родителю.
