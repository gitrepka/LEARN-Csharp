# 2.2. Виртуальные методы: Переопределение судьбы

Иногда родитель дает наследнику метод, но наследник хочет выполнять его по-своему.

---

## 1. virtual и override

*   **virtual** (в родителе) — говорит: "Я разрешаю наследникам менять этот метод".
*   **override** (в наследнике) — говорит: "Я меняю логику родителя на свою".

```csharp
class Animal
{
    public virtual void MakeSound() => Console.WriteLine("Голос!");
}

class Cat : Animal
{
    public override void MakeSound() => Console.WriteLine("Мяу!");
}

class Dog : Animal
{
    public override void MakeSound() => Console.WriteLine("Гав!");
}
```

---

## 2. Магия Полиморфизма

Почему это круто? Потому что ты можешь работать с животными в общем виде, а они будут вести себя по-разному.

```csharp
Animal[] farm = { new Cat(), new Dog(), new Animal() };

foreach (var animal in farm)
{
    animal.MakeSound(); // Каждый издаст СВОЙ звук
}
```
*   `Cat` скажет "Мяу".
*   `Dog` скажет "Гав".
*   Обычный `Animal` скажет "Голос".

---

## 3. base.Method()

Если наследник хочет выполнить код родителя **И** добавить свой:

```csharp
class SuperZombie : Zombie
{
    public override void Move()
    {
        base.Move(); // Выполнили обычное движение
        Console.WriteLine("...и очень быстро!"); // Добавили эффект
    }
}
```

## 5. Резюме
*   `virtual` — можно менять.
*   `override` — меняю.
*   Это позволяет писать универсальный код для разных объектов.
