# 3.3. Логические операторы

Как принимать сложные решения? "Если у меня есть деньги И магазин открыт, я куплю хлеб".
Для этого нужны логические операторы.

---

## 1. Основная тройка

### && (И / AND)
Возвращает `true`, только если **ОБА** условия верны.
```csharp
bool hasMoney = true;
bool isOpen = false;
bool canBuy = hasMoney && isOpen; // false (одно из условий провалено)
```

### || (ИЛИ / OR)
Возвращает `true`, если **ХОТЯ БЫ ОДНО** условие верно.
```csharp
bool hasKey = false;
bool canPickLock = true;
bool canEnter = hasKey || canPickLock; // true (нет ключа, но взломал)
```

### ! (НЕ / NOT)
Инвертирует значение.
```csharp
bool isRaining = true;
bool isDry = !isRaining; // false
```

---

## 2. Короткое замыкание (Short-circuit evaluation)

Это важнейшая фича C# для производительности и безопасности.

### Для && (И):
Если левая часть `false`, правую часть компьютер **даже не проверяет**. Зачем? Ведь результат всё равно будет `false`.

```csharp
string s = null;
// Если бы не короткое замыкание, вторая часть (s.Length) вызвала бы краш!
// Но так как s != null дает false, проверка останавливается.
if (s != null && s.Length > 0) 
{
    Console.WriteLine("Строка не пуста");
}
```

### Для || (ИЛИ):
Если левая часть `true`, правую компьютер не проверяет. (Результат уже точно `true`).

```csharp
// Метод HeavyCheck() даже не запустится, если x == 10.
if (x == 10 || HeavyCheck()) { ... }
```

---

## 3. Приоритет

1.  `!` (самый высокий)
2.  `&&`
3.  `||` (самый низкий)

`if (A || B && C)` читается как `if (A || (B && C))`.
Ставь скобки, если сомневаешься!

## 4. Практика

### Задание 3.3.1: Фейсконтроль
Напиши код, проверяющий, может ли человек войти в клуб.
Условия (переменные):
*   `age` (должен быть >= 18)
*   `isVIP` (если VIP, то возраст не важен)
*   `isBanned` (если забанен, то нельзя никому, даже VIP)

```csharp
bool canEnter = !isBanned && (age >= 18 || isVIP);
```

---

## 5. Резюме
*   `&&` — оба верны.
*   `||` — хотя бы один.
*   Короткое замыкание спасает от ошибок (`null check`) и экономит ресурсы.
