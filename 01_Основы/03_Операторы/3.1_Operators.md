## Объяснение

### ЗАЧЕМ?
Типы данных — это ингредиенты. Операторы — это рецепты. Без операторов ты не можешь ничего СДЕЛАТЬ с данными: сложить числа, сравнить значения, проверить условия.

### Арифметические операторы

```csharp
int a = 10, b = 3;

Console.WriteLine(a + b);   // 13 — сложение
Console.WriteLine(a - b);   // 7  — вычитание
Console.WriteLine(a * b);   // 30 — умножение
Console.WriteLine(a / b);   // 3  — целочисленное деление! (не 3.33)
Console.WriteLine(a % b);   // 1  — остаток от деления (10 / 3 = 3, остаток 1)

// Для дробного деления хотя бы один операнд должен быть дробным:
Console.WriteLine(10.0 / 3);   // 3.3333...
Console.WriteLine((double)a / b); // 3.3333... — приведение типа
```

**Инкремент и декремент:**
```csharp
int x = 5;

// Постфиксный: СНАЧАЛА использует, ПОТОМ увеличивает
Console.WriteLine(x++); // Выведет 5, потом x станет 6

// Префиксный: СНАЧАЛА увеличивает, ПОТОМ использует
Console.WriteLine(++x); // x сначала станет 7, выведет 7
```

**checked / unchecked — контроль переполнения:**
```csharp
// Что если число слишком большое?
int max = int.MaxValue; // 2 147 483 647

// По умолчанию — тихо переполнится!
int overflow = max + 1; // -2 147 483 648 (???)

// checked — кинет исключение при переполнении
checked
{
    int safe = max + 1; // OverflowException!
}
```

### Операторы сравнения

```csharp
int x = 5, y = 10;

Console.WriteLine(x == y);  // False — равно
Console.WriteLine(x != y);  // True  — не равно
Console.WriteLine(x < y);   // True  — меньше
Console.WriteLine(x > y);   // False — больше
Console.WriteLine(x <= 5);  // True  — меньше или равно
Console.WriteLine(x >= 10); // False — больше или равно
```

### Логические операторы

```csharp
bool hasKey = true;
bool doorOpen = false;

// && — И (оба должны быть true)
Console.WriteLine(hasKey && doorOpen);  // False

// || — ИЛИ (хотя бы один true)
Console.WriteLine(hasKey || doorOpen);  // True

// ! — НЕ (инвертирует)
Console.WriteLine(!doorOpen);           // True
```

**Короткое замыкание (short-circuit):**
```csharp
// && останавливается на первом false
// || останавливается на первом true
string? name = null;
bool valid = name != null && name.Length > 0; // НЕ упадёт!
// Если name == null, name.Length вообще не вызывается
```

### Побитовые операторы

```csharp
int a = 0b1010;  // 10 в двоичной
int b = 0b1100;  // 12 в двоичной

Console.WriteLine(a & b);   // 0b1000 = 8  — побитовое И
Console.WriteLine(a | b);   // 0b1110 = 14 — побитовое ИЛИ
Console.WriteLine(a ^ b);   // 0b0110 = 6  — XOR (исключающее ИЛИ)
Console.WriteLine(~a);      // инверсия всех битов
Console.WriteLine(a << 1);  // 0b10100 = 20 — сдвиг влево (×2)
Console.WriteLine(a >> 1);  // 0b0101 = 5   — сдвиг вправо (÷2)

// >>> — беззнаковый сдвиг вправо (C# 11)
Console.WriteLine(-1 >>> 1); // огромное положительное число
```

Побитовые операторы полезны для: флагов `[Flags] enum`, оптимизации, работы с цветами (RGB).

### Тернарный оператор

```csharp
int health = 30;
string status = health > 50 ? "Здоров" : "Ранен";
// Читается: "если health > 50, то 'Здоров', иначе 'Ранен'"

// В Godot:
float speed = isRunning ? 200f : 100f;
```

### Null-операторы (самые важные!)

```csharp
// ?? — если null, то значение по умолчанию
string? input = null;
string name = input ?? "Гость";  // "Гость"

// ?. — безопасный доступ к члену
string? text = null;
int? len = text?.Length;  // null (не NullReferenceException!)

// ??= — присвоить если null
string? greeting = null;
greeting ??= "Привет";  // greeting = "Привет"
greeting ??= "Пока";    // greeting всё ещё "Привет" (уже не null)

// Цепочка:
string display = player?.Weapon?.Name ?? "Без оружия";
```

### Приоритет операторов (от высокого к низкому)

| Приоритет | Операторы |
|-----------|-----------|
| 1 (высший) | `x++`, `x--`, `?.`, `?[]` |
| 2 | `!`, `~`, `++x`, `--x`, приведение `(T)` |
| 3 | `*`, `/`, `%` |
| 4 | `+`, `-` |
| 5 | `<<`, `>>` |
| 6 | `<`, `>`, `<=`, `>=`, `is`, `as` |
| 7 | `==`, `!=` |
| 8 | `&` |
| 9 | `^` |
| 10 | `\|` |
| 11 | `&&` |
| 12 | `\|\|` |
| 13 | `??` |
| 14 | `? :` (тернарный) |
| 15 (низший) | `=`, `+=`, `-=`, `*=` и т.д. |

**Совет:** Если не уверен — ставь скобки! `(a + b) * c` понятнее чем `a + b * c`.

## Частые ошибки

### 1. Целочисленное деление
```csharp
// ❌ Ожидал 3.33, получил 3
int result = 10 / 3;

// ✅ Приведи к double:
double result = 10.0 / 3;   // или (double)10 / 3
```

### 2. = вместо ==
```csharp
// ❌ Присваивание, не сравнение!
if (x = 5) { }  // Ошибка компиляции в C# (в C++ — беда)

// ✅ Двойное равно для сравнения:
if (x == 5) { }
```

### 3. Путаница prefix/postfix
```csharp
int a = 5;
Console.WriteLine(a++ + ++a);
// a++ → использует 5, потом a=6
// ++a → a=7, использует 7
// 5 + 7 = 12
// Лучше НЕ писать такой код — разбивай на строки!
```
