# 3.2. Присваивание и Сравнение

Программирование состоит из двух вещей: изменение данных (присваивание) и принятие решений (сравнение).

---

## 1. Операторы присваивания

Базовое присваивание — это `=`. Но программисты ленивы, поэтому придумали "составные" операторы.

```csharp
int x = 10;

x += 5;  // То же, что x = x + 5; (стало 15)
x -= 3;  // То же, что x = x - 3; (стало 12)
x *= 2;  // То же, что x = x * 2; (стало 24)
x /= 4;  // То же, что x = x / 4; (стало 6)
x %= 5;  // То же, что x = x % 5; (стало 1)
```

**Зачем это?** Код становится чище и его быстрее читать. `x += 5` сразу говорит: "Увеличить на 5".

---

## 2. Операторы сравнения

Эти операторы всегда возвращают `bool` (`true` или `false`).

*   `==` (Равно) — ⚠️ Не путай с присваиванием `=`!
*   `!=` (Не равно)
*   `>` (Больше)
*   `<` (Меньше)
*   `>=` (Больше или равно)
*   `<=` (Меньше или равно)

```csharp
int age = 18;
bool isAdult = (age >= 18); // true

int lives = 0;
bool isDead = (lives == 0); // true
```

### Сравнение строк
Сравнивать строки через `==` в C# можно (в отличие от Java), но есть нюанс с регистром.

```csharp
string a = "Hello";
string b = "hello";
Console.WriteLine(a == b); // False! (Регистр важен)
```

Если нужно сравнить без учета регистра (например, логин пользователя), используют метод:
`a.Equals(b, StringComparison.OrdinalIgnoreCase)`

---

## 3. Сравнение ссылочных типов (Опасно!)

Помнишь про Стек и Кучу?
*   Для `int`, `bool` и других значимых типов `==` сравнивает **значения**.
*   Для классов (кроме `string` и `record`) `==` сравнивает **адреса в памяти**.

```csharp
// Представь, что мы создали класс User
var u1 = new User("Alex");
var u2 = new User("Alex");

Console.WriteLine(u1 == u2); // FALSE! Это два разных объекта в памяти.
```
*(Как научить классы сравниваться "по-человечески", мы изучим в теме ООП).*

## 5. Резюме
*   `+=`, `-=` — синтаксический сахар.
*   `==` — проверка равенства, `=` — присваивание.
