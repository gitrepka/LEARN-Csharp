# 3.4. Побитовые операции

Это магия низкого уровня. Здесь мы работаем с числами не как с математическими величинами, а как с набором бит (0 и 1).
Это критически важно в **GameDev** (слои коллизий в Godot/Unity) и системном программировании.

---

## 1. Битовые операторы

Представим число 5 и 3 в двоичном виде (byte):
5 = `0000 0101`
3 = `0000 0011`

### & (Побитовое И / AND)
Бит равен 1, только если оба бита равны 1.
```csharp
  0000 0101 (5)
& 0000 0011 (3)
  ---------
  0000 0001 (1)
```

### | (Побитовое ИЛИ / OR)
Бит равен 1, если хотя бы один бит равен 1.
```csharp
  0000 0101 (5)
| 0000 0011 (3)
  ---------
  0000 0111 (7)
```

### ^ (XOR — Исключающее ИЛИ)
Бит равен 1, если биты **разные**. (Очень полезно для шифрования).
```csharp
  0000 0101 (5)
^ 0000 0011 (3)
  ---------
  0000 0110 (6)
```

### ~ (Инверсия / NOT)
Меняет 0 на 1 и наоборот.
`~0000 0101` -> `1111 1010`

## 2. Битовые сдвиги (<< и >>)

Двигает биты влево или вправо.
*   Сдвиг влево (`<< 1`) — это умножение на 2.
*   Сдвиг вправо (`>> 1`) — это деление на 2.

```csharp
int a = 1;      // 0001
int b = a << 2; // 0100 (стало 4)
```

В Godot слои физики (Collision Layers) — это биты.
*   Слой 1: `1 << 0` (1)
*   Слой 2: `1 << 1` (2)
*   Слой 3: `1 << 2` (4)

---

## 3. Флаги (Flags) — Практическое применение

Представь настройки файла: "Только чтение", "Скрытый", "Системный". Хранить 3 bool переменные — дорого. Можно хранить всё в одном `byte`.

```csharp
const byte ReadOnly = 1; // 001
const byte Hidden   = 2; // 010
const byte System   = 4; // 100

// Создаем файл: Скрытый И Системный
byte myFile = Hidden | System; // 110 (6)

// Проверяем: Является ли он скрытым? (Маска)
bool isHidden = (myFile & Hidden) == Hidden; // true
```

## 5. Резюме
*   `|` — объединить флаги (включить).
*   `&` — проверить флаг.
*   `<<` — получить степень двойки (1, 2, 4, 8...).
