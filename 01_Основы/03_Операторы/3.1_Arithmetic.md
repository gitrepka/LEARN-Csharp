# 3.1. Арифметические операторы

Математика — это основа программирования. В C# есть стандартные операторы, но у них есть свои "подводные камни", особенно когда речь идет о типах данных.

---

## 1. Базовые операторы

*   `+` (Сложение)
*   `-` (Вычитание)
*   `*` (Умножение)
*   `/` (Деление)
*   `%` (Остаток от деления)

### Особенность деления целых чисел
Если ты делишь `int` на `int`, результат **всегда** будет `int`. Дробная часть просто отбрасывается.

```csharp
int a = 7;
int b = 2;
Console.WriteLine(a / b); // Выведет 3, а не 3.5!

// Чтобы получить 3.5, хотя бы одно число должно быть дробным:
Console.WriteLine(7.0 / 2); // 3.5
```

### Остаток от деления (%)
Это очень полезный оператор. Например, чтобы узнать, четное ли число:
```csharp
int n = 10;
bool isEven = (n % 2 == 0); // Если остаток от деления на 2 равен 0 — число четное.
```

---

## 2. Инкремент и Декремент

Эти операторы изменяют значение переменной на 1.

*   `++` (Инкремент): `x = x + 1`
*   `--` (Декремент): `x = x - 1`

### Префикс vs Постфикс (Важно!)

*   **Постфиксный (`x++`):** Сначала возвращает значение, ПОТОМ прибавляет 1.
*   **Префиксный (`++x`):** Сначала прибавляет 1, ПОТОМ возвращает значение.

```csharp
int a = 5;
int b = a++; // b = 5, потом a станет 6
Console.WriteLine($"a: {a}, b: {b}"); // a: 6, b: 5

int c = 5;
int d = ++c; // c станет 6, потом d = 6
Console.WriteLine($"c: {c}, d: {d}"); // c: 6, d: 6
```

---

## 3. Приоритет операций

Все как в школе: умножение и деление выполняются раньше сложения. Используй скобки `()`, чтобы изменить порядок.

1.  Скобки `()`
2.  Инкремент/Декремент `++`, `--`
3.  Умножение, деление и остаток `*`, `/`, `%`
4.  Сложение и вычитание `+`, `-`

### Godot (Движение и здоровье)
Создай скрипт. Сделай так, чтобы при каждом нажатии кнопки (или в `_Ready`) здоровье игрока (`Health`) уменьшалось на 1 (`--`), а опыт (`XP`) увеличивался на 10. Выведи остаток от деления `XP` на 100 — это будет прогресс текущего уровня.
