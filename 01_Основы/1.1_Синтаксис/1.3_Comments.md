# 1.3. Комментарии и документация: Искусство молчания

Код — это письмо, которое ты пишешь не только компьютеру, но и другим программистам (и себе будущему). Комментарии помогают понять суть, когда код становится сложным.

---

## 1. Простые комментарии

### Однострочный (`//`)
Всё, что после `//` и до конца строки, игнорируется компилятором.

```csharp
int x = 10; // Инициализируем счетчик (Плохой комментарий - это и так видно!)
```

### Многострочный (`/* ... */`)
Позволяет писать целые абзацы.

```csharp
/*
  Этот алгоритм использует метод пузырьковой сортировки.
  Он не самый эффективный, но простой для понимания.
  TODO: Переписать на QuickSort в следующей версии.
*/
void Sort() { ... }
```
*Совет:* Используй ключевые слова **TODO** или **FIXME**. IDE (Rider/VS) подсвечивает их и собирает в список задач.

---

## 2. XML-документация (`///`) — Стандарт Профи

Если ты напишешь три слеша `///` над классом или методом, IDE сгенерирует шаблон документации.

**Зачем это нужно?**
Когда ты (или другой программист) будете вызывать этот метод в другом месте кода и наведете на него мышку, всплывет красивая подсказка с твоим текстом. Это "встроенная инструкция".

```csharp
/// <summary>
/// Вычисляет урон по врагу с учетом его брони.
/// </summary>
/// <param name="damage">Базовый урон оружия.</param>
/// <param name="armor">Количество брони цели (от 0 до 100).</param>
/// <returns>Итоговый урон, который будет нанесен.</returns>
/// <exception cref="ArgumentException">Выбрасывается, если броня меньше нуля.</exception>
public int CalculateDamage(int damage, int armor)
{
    if (armor < 0) throw new ArgumentException("Armor cannot be negative");
    return damage * (100 - armor) / 100;
}
```

### Основные теги:
*   `<summary>`: Краткое описание (что делает метод).
*   `<param name="...">`: Описание аргумента.
*   `<returns>`: Что метод возвращает.
*   `<see cref="..."/>`: Ссылка на другой класс или метод (кликабельная в IDE!).

## 3. Философия: Хороший vs Плохой комментарий

**Плохо (Шум):**
Комментарий дублирует код.
```csharp
// Прибавляем 1 к i
i++; 
```

**Плохо (Враньё):**
Код изменился, а комментарий забыли обновить. Это хуже, чем отсутствие комментария.

**Хорошо (Объяснение "Почему"):**
Объясняет намерение или неочевидный хак.
```csharp
// Делим на 2 сдвигом, так как это быстрее на старых процессорах
int result = value >> 1; 
```

## 5. Резюме
*   `//` для быстрых заметок и TODO.
*   `///` для публичных методов (API). Это создает "интерактивную справку".
*   Комментарий должен отвечать на вопрос **"Почему?"**, а не "Что?".
