# 7.1. Основы методов: Анатомия функции

Метод — это именованный блок кода, который делает одну конкретную задачу.
Зачем они нужны?
1. **DRY (Don't Repeat Yourself)** — не пиши один и тот же код дважды.
2. **Читаемость** — код превращается в список понятных действий.

---

## 1. Анатомия метода

```csharp
// [модификатор] [тип_возврата] [ИмяМетода] ([параметры])
public int AddNumbers(int a, int b)
{
    int sum = a + b;
    return sum; // Возврат результата
}
```

### Разбор частей:
*   **Модификатор доступа** (например, `public` или `static`): Кто может вызывать этот метод. Пока мы работаем в `Program.cs`, будем использовать `static`.
*   **Тип возврата**: Что метод отдает после работы (`int`, `string`, `bool`).
*   **void**: Если метод ничего не возвращает (просто выводит в консоль или меняет переменную), пишем `void`.
*   **Имя метода**: Всегда начинается с **Большой буквы** (PascalCase). Должно быть глаголом: `Eat()`, `CalculateDamage()`, `GetUserName()`.
*   **Параметры**: Входящие данные в скобках.

---

## 2. Ключевое слово return

`return` делает две вещи:
1.  Останавливает выполнение метода.
2.  Выбрасывает результат наружу.

Если метод `void`, можно написать `return;` без значения, чтобы просто выйти из метода раньше времени.

---

## 3. Методы-выражения (Expression-bodied)

Если в методе всего одна строка, его можно написать красиво через стрелочку `=>`.

```csharp
// Обычный вид
public int Square(int x) 
{
    return x * x;
}

// Короткий вид (то же самое)
public int Square(int x) => x * x;
```

## 5. Резюме
*   Имя метода — это Глагол с Большой Буквы.
*   `void` — ничего не возвращаем.
*   `=>` — для коротких методов.
