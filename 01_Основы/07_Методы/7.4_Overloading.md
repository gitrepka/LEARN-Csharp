# 7.4. Перегрузка методов (Overloading)

В C# можно иметь несколько методов с **одинаковым именем**, если у них разные наборы параметров.
Это называется **Сигнатура метода**. Она состоит из имени и типов параметров (их количество и порядок).

---

## 1. Зачем это нужно?

Представь метод `Print`. Ты хочешь выводить и числа, и строки.
Плохо: `PrintInt(5)`, `PrintString("Hi")`.
Хорошо: `Print(5)`, `Print("Hi")`.

```csharp
static void Print(int val) => Console.WriteLine($"Число: {val}");

static void Print(string val) => Console.WriteLine($"Строка: {val}");

static void Print(int val, string prefix) => Console.WriteLine($"{prefix}: {val}");
```

Компилятор сам понимает, какой метод вызвать, глядя на то, что ты передаешь в скобках.

---

## 2. Правила перегрузки

Чтобы перегрузка работала, методы **должны** отличаться:
1.  Количеством параметров.
2.  Типами параметров.
3.  Или использованием `ref` / `out`.

**Важно:** Перегрузка **НЕ** может отличаться только типом возвращаемого значения.
```csharp
static int GetValue() { ... }
static string GetValue() { ... } // ОШИБКА! Компилятор запутается.
```

---

## 3. Практика: Площади фигур

### Задание 7.4.1
Создай три перегрузки метода `GetArea`:
1.  `double GetArea(double side)` — для квадрата (side * side).
2.  `double GetArea(double width, double height)` — для прямоугольника.
3.  `double GetArea(double radius, bool isCircle)` — для круга (Pi * r^2). Параметр `isCircle` просто помогает отличить метод от квадрата.

---

## 4. Резюме
*   Одно имя — много реализаций.
*   Сигнатура = Имя + Параметры.
*   Тип возврата не влияет на перегрузку.
