## 1. Локальные функции

В C# можно объявлять один метод **внутри** другого.
Зачем? Чтобы не "засорять" класс мелкими вспомогательными методами, которые нужны только в одном месте.

```csharp
public void ProcessData(int x)
{
    // Локальная функция
    int Double(int val) => val * 2;

    int result = Double(x);
    Console.WriteLine(result);
}
```
Локальные функции имеют доступ ко всем переменным внешнего метода (замыкание).

---

## 2. Рекурсия

Рекурсия — это когда метод **вызывает сам себя**.
Это как два зеркала друг напротив друга.

Чтобы рекурсия не длилась вечно и не вызвала ошибку `StackOverflowException` (переполнение стека), у неё всегда должны быть две части:
1.  **Базовый случай (Условие выхода)** — когда мы останавливаемся.
2.  **Рекурсивный шаг** — самовызов.

### Классический пример: Факториал (5! = 5*4*3*2*1)

```csharp
static int Factorial(int n)
{
    if (n <= 1) return 1; // Базовый случай
    
    return n * Factorial(n - 1); // Рекурсивный шаг
}
```

### Как это работает в памяти?
Каждый вызов метода создает новую "тарелку" в **Стеке** (Call Stack). Если вызовов слишком много (например, миллион), память стека кончится, и программа упадет. 
Поэтому рекурсию нужно использовать осторожно.
