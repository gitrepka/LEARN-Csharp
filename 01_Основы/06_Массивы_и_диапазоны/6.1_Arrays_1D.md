# 6.1. Одномерные массивы

Массив — это набор переменных одного типа, расположенных в памяти **вплотную** друг к другу.

---

## 1. Объявление и Создание

Массивы в C# — это ссылочные типы (живут в Куче), но их размер фиксируется **в момент создания**.

```csharp
// 1. Пустой массив на 5 элементов (заполнен нулями)
int[] numbers = new int[5];

// 2. Сразу с данными
string[] names = { "Alex", "Bob", "Clara" };

// 3. Через new и значения
double[] prices = new double[] { 10.5, 20.0, 5.99 };
```

---

## 2. Доступ и Память

Индексы начинаются с **0**. 
Если в массиве 5 элементов, последний индекс — **4**.

```csharp
int[] data = { 10, 20, 30 };
data[0] = 100; // Изменили первый элемент
Console.WriteLine(data[2]); // Прочитали третий (30)
```

### ⚠️ Опасность: IndexOutOfRangeException
Если ты попробуешь обратиться к `data[3]`, программа крашнется. C# строго следит за границами.

---

## 3. Свойства и Методы

*   `Length`: Возвращает количество элементов (только чтение).
*   `Array.Sort(arr)`: Сортирует массив.
*   `Array.Reverse(arr)`: Переворачивает задом наперед.
*   `Array.Clear(arr, 0, arr.Length)`: Обнуляет массив.

---

## 4. Копирование массивов

Помнишь про Ссылочные типы?
`int[] arr2 = arr1;` — это **НЕ** копия массива, это две переменные, смотрящие на один и тот же список.
Чтобы сделать настоящую копию, используй `.Clone()` или `Array.Copy()`.

*   Массив — фиксированный размер.
