# 2.1. Переменные и Память: Стек и Куча

Это **самый важный урок** во всем курсе для понимания C#. Если ты поймешь разницу между Стеком и Кучей, ты избежишь 90% ошибок новичков.

---

## 1. Что такое переменная?

Когда ты пишешь `int age = 20;`, компьютер делает три вещи:
1.  **Выделяет память**: Находит свободное место (ячейку).
2.  **Дает имя**: Связывает имя `age` с адресом этой ячейки (например, `0x1234`).
3.  **Записывает значение**: Кладет число `20` в эту ячейку.

Но *где именно* выделяется эта память? В C# есть два типа памяти.

---

## 2. Стек (Stack) — "Рюкзак за спиной"

Стек — это оперативная память для текущего выполнения.
*   **Свойства:** Очень быстрая. Маленькая (обычно 1 МБ на поток).
*   **Принцип:** LIFO (Last In, First Out). Как стопка тарелок: положил сверху — взял сверху.
*   **Жизнь:** Данные живут только пока выполняется метод. Как только метод (`Main` или другой) завершается — всё, что было в его стеке, мгновенно уничтожается.

### Кто живет в Стеке?
**Значимые типы (Value Types):**
*   Все числа (`int`, `double`, `byte`...)
*   Логика (`bool`)
*   Символы (`char`)
*   Структуры (`struct`)

**Пример:**
```csharp
void Calc() 
{
    int a = 10; // Лежит в стеке
    int b = 20; // Лежит поверх a
} // <-- Метод кончился. a и b мгновенно удалены.
```

---

## 3. Куча (Heap) — "Большой склад"

Куча — это огромная область памяти (вся твоя RAM).
*   **Свойства:** Медленнее стека (нужно искать место). Огромная (гигабайты).
*   **Жизнь:** Данные живут, пока они кому-то нужны. Если на объект никто не ссылается, приходит **Garbage Collector (Мусорщик)** и удаляет его.

### Кто живет в Куче?
**Ссылочные типы (Reference Types):**
*   Строки (`string`)
*   Массивы (`int[]`, `string[]`)
*   Классы (`class`)

---

## 4. Главное отличие: Копирование vs Ссылка

### Значимые типы (Value Types)
В переменной лежит **само значение**.
При присваивании значение **копируется**.

```csharp
int x = 10;
int y = x; // y = 10 (копия)
x = 20;
// y всё ещё 10. Они независимы.
```

### Ссылочные типы (Reference Types)
В переменной (в стеке) лежит **адрес** (ссылка) на объект в куче.
При присваивании копируется **адрес**, а не сам объект.

```csharp
int[] a = { 1, 2 }; // В 'a' лежит адрес (например, 0x99)
int[] b = a;        // В 'b' копируется адрес 0x99

a[0] = 500;         // Идем по адресу 0x99 и меняем данные

Console.WriteLine(b[0]); // Выведет 500! Потому что b смотрит туда же.
```
*Аналогия:* 
`Value Type` — это файл на твоем рабочем столе. Если ты скопируешь его другу, у него будет *свой* файл. Если он изменит свой, твой не изменится.
`Reference Type` — это ссылка на Google Doc. Если ты скинешь ссылку другу, вы будете редактировать *один и тот же* документ.

## 5. Практика: Почувствуй это

### Задание 2.1.1: Эксперимент с массивом
1.  Создай массив `int[] numbers1 = { 1, 2, 3 };`
2.  Создай вторую переменную `int[] numbers2 = numbers1;`
3.  Измени `numbers2[0] = 99;`
4.  Выведи `numbers1[0]`.
5.  Убедись, что оно изменилось. Ты только что доказал, что массив — ссылочный тип.

---

## 6. Резюме
*   **Стек** — для простых типов (int, bool). Быстро, копируется значением.
*   **Куча** — для сложных типов (string, array, class). Медленнее, копируется ссылкой.
*   Понимание этого спасет тебя от часов отладки "почему мои данные изменились сами собой".
