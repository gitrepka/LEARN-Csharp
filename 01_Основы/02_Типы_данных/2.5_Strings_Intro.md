# 2.5. Строки: Первое знакомство

Строка (`string`) — это последовательность символов (`char`).
Но в C# это особенный тип.

---

## 1. Ссылочный тип (Reference Type)
В отличие от `int` или `char`, строка живет в **Куче** (Heap).
Переменная `string name` хранит лишь адрес в памяти, где лежит текст.

## 2. Неизменяемость (Immutability)
Это самое важное свойство строк в C#.
**Строку нельзя изменить после создания.**

```csharp
string s = "Hello";
s[0] = 'M'; // ОШИБКА КОМПИЛЯЦИИ! Нельзя менять буквы внутри.
```

Когда ты делаешь "изменение", ты на самом деле создаешь **новую** строку.

```csharp
string a = "Hello";
string b = a + " World"; 
// 1. Берется "Hello"
// 2. Берется " World"
// 3. Выделяется НОВАЯ память под "Hello World"
// 4. 'b' указывает на новую память.
// 'a' осталась "Hello"!
```

### Зачем так сделано?
Для безопасности и многопоточности. Если строка неизменяема, её можно безопасно передавать куда угодно, не боясь, что кто-то испортит данные внутри.

---

## 3. Объединение (Конкатенация)
Самый простой способ склеить строки — `+`.

```csharp
string firstName = "John";
string lastName = "Doe";
string fullName = firstName + " " + lastName;
```

*Примечание:* Если нужно склеить много строк (например, в цикле 1000 раз), `+` будет работать очень медленно из-за создания кучи временных объектов. Для этого есть `StringBuilder` (о нем в модуле 5).

---

## 4. Пустая строка vs null
*   `""` (или `string.Empty`) — это "пустая коробка". Объект есть, длина 0.
*   `null` — коробки нет вообще. Любая попытка обратиться к ней (`null.Length`) вызовет краш программы (`NullReferenceException`).

## 5. Практика

### Задание 2.5.1
1.  Создай строку `string s1 = "Test";`.
2.  Присвой `string s2 = s1;`.
3.  Присвой `s1 = "New";`.
4.  Выведи `s2`. Что там осталось? "Test" или "New"?
5.  Объясни результат, вспомнив про неизменяемость.

---

## 6. Резюме
*   Строки живут в куче.
*   Строки нельзя менять (они Immutable). Любая операция создает новую строку.
