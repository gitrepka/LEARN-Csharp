# 2.6. Автоматизация и Константы

C# — язык со строгой типизацией. Но иногда можно писать меньше кода.

---

## 1. Ключевое слово var

`var` позволяет компилятору самому угадать тип переменной по её значению.

```csharp
var age = 25;       // Компилятор видит 25 (int) -> age становится int
var name = "Alice"; // Компилятор видит "" (string) -> name становится string
```

### ⚠️ ЭТО НЕ DYNAMIC!
`var` работает только в момент компиляции. После этого переменная становится обычным `int` или `string`.
Ты **не можешь** поменять тип потом:

```csharp
var x = 10;
x = "Hello"; // ОШИБКА! x уже int.
```

### Когда использовать var?
**ДА:** Когда тип очевиден из правой части.
```csharp
var sb = new StringBuilder(); // Ясно, что это StringBuilder
var users = new Dictionary<string, int>(); // Короче, чем писать тип дважды
```

**НЕТ:** Когда тип неясен.
```csharp
var result = GetData(); // Что это? int? string? bool? Приходится наводить мышку.
// Лучше:
int result = GetData();
```

## 2. Константы (const)

Иногда нужно закрепить значение навсегда.

```csharp
const double Pi = 3.14159;
const int MaxLives = 3;
```

**Правила const:**
1.  Обязана быть инициализирована сразу.
2.  Значение должно быть известно **во время компиляции** (число, строка). Нельзя присвоить результат вызова метода.
3.  Её нельзя изменить.

**Зачем?** Чтобы не было "магических чисел" в коде. Вместо `if (lives < 3)` лучше писать `if (lives < MaxLives)`.

---

## 3. Значения по умолчанию (default)

У каждого типа есть "пустое" значение.

```csharp
int a = default;       // 0
bool b = default;      // false
string c = default;    // null
```
Это полезно в дженериках (которые мы изучим позже).
