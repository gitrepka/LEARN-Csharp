# 2.3. Дробные числа: Точность против Скорости

В C# есть три способа хранить "числа с запятой". Новички часто путают их, что приводит к финансовым потерям или тормозам в играх.

---

## 1. float и double (Бинарная плавающая точка)

Компьютер хранит эти числа в формате **IEEE 754**. Это как "научная нотация" (1.5 × 10^2), только в двоичной системе.

### float (System.Single)
*   **Размер:** 4 байта (32 бита).
*   **Точность:** ~6-9 знаков.
*   **Суффикс:** `f` (обязательно!). `float x = 3.5f;`
*   **Где нужен:** Игры (координаты, скорости), графика, ML. Там, где 1 миллион точек важнее, чем ошибка в 0.000001.

### double (System.Double) — Стандарт
*   **Размер:** 8 байт (64 бита).
*   **Точность:** ~15-17 знаков.
*   **Суффикс:** `d` (необязателен). `double x = 3.5;`
*   **Где нужен:** Научные расчеты, координаты GPS, общая математика.

### ⚠️ Проблема точности
В двоичной системе нельзя точно записать число `0.1` (как в десятичной нельзя записать 1/3 = 0.333...).

```csharp
double a = 0.1;
double b = 0.2;
Console.WriteLine(a + b == 0.3); // False!
// На самом деле там 0.30000000000000004
```
**Вывод:** Никогда не сравнивай `double` через `==`. Используй дельту: `Math.Abs(a - b) < 0.0001`.

---

## 2. decimal (Десятичная фиксированная точка)

Это уникальный тип для C#.

*   **Размер:** 16 байт (128 бит). Тяжелый!
*   **Точность:** 28-29 знаков.
*   **Суффикс:** `m` (Money). `decimal price = 10.99m;`
*   **Особенность:** Хранит числа как обычные целые + положение запятой. Поэтому `0.1` в decimal — это ровно `0.1`.

### Когда использовать?
**ВСЕГДА**, когда речь идет о деньгах.
*   Зарплаты
*   Цены
*   Банковские транзакции

Использование `double` для денег — это профессиональная ошибка, за которую увольняют.

## 3. Таблица выбора

| Задача | Тип | Пример |
| :--- | :--- | :--- |
| Здоровье игрока, скорость машины | **float** | `50.5f` |
| Расстояние между звездами, физика | **double** | `150.0` |
| Цена товара, баланс кошелька | **decimal** | `99.90m` |

---

## 5. Резюме
*   **float** — для игр (`f`).
*   **double** — для науки (`d` или без суффикса).
*   **decimal** — для денег (`m`).
*   `0.1 + 0.2` в double не равно `0.3`.
