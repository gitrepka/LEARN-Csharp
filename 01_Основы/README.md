# Модуль 1: Основы C# — Фундамент

> Ссылка на план: `PLAN_CSHARP_MASTER.md` → Модуль 0-1
> Недели: 1-5 по SPIRAL_SCHEDULE.md

## Структура папок
```
01_Синтаксис/          — namespace, using, global using, структура программы
02_Типы_данных/        — value types, reference types, nullable, var, const
03_Операторы/          — арифметические, логические, побитовые, null-операторы
04_Условия_и_циклы/    — if/switch/for/while/foreach
05_Строки/             — методы строк, StringBuilder, форматирование, Span
06_Массивы_и_диапазоны/ — массивы, Index (^), Range (..), Span<T>
07_Методы/             — параметры, перегрузка, рекурсия, extension methods
08_Regex/              — регулярные выражения, GeneratedRegex
09_Дата_и_время/       — DateTime, TimeSpan, DateOnly, TimeZoneInfo
10_Глобализация/       — CultureInfo, форматирование, .resx
```

## Как использовать
1. Заходишь в папку текущей темы
2. Создаёшь подпапки для практики:
   - `Uno_Practice/` — проекты Uno Platform
   - `Godot_Practice/` — проекты Godot
   - `Mini_Exercises/` — файлы с мини-упражнениями (.cs)
3. Файл `notes.md` — твои заметки по теме
