# 4.1. Условия (if/else): Развилка дорог

Программа без условий — это просто калькулятор. Условия позволяют коду реагировать на ситуацию.

---

## 1. Классический if / else

```csharp
int hp = 80;

if (hp <= 0)
{
    Console.WriteLine("Game Over");
}
else if (hp < 50)
{
    Console.WriteLine("Нужно лечиться!");
}
else
{
    Console.WriteLine("В бой!");
}
```
**Совет:** Всегда используй фигурные скобки `{}`, даже если внутри одна строка. Это спасет от глупых ошибок при добавлении второй строки.

---

## 2. Тернарный оператор (?:)

Короткий способ записать `if-else` в одну строку. Используется для присваивания.

**Синтаксис:** `(условие) ? (если true) : (если false)`

```csharp
int age = 20;
string status = (age >= 18) ? "Взрослый" : "Ребенок";

// Можно даже вкладывать (но не увлекайся!):
string type = (age < 13) ? "Child" : (age < 20) ? "Teen" : "Adult";
```

---

## 3. Вложенные условия (Nested Ifs)

```csharp
if (isAlive)
{
    if (hasKey)
    {
        OpenDoor();
    }
}
```
**Совет:** Избегай глубокой вложенности ("Arrow Code"). Лучше объединять условия (`&&`) или использовать "Guard Clauses" (ранний выход).

**Guard Clause (Красиво):**
```csharp
void EnterRoom()
{
    if (!isAlive) return; // Ранний выход
    if (!hasKey) return;  // Ранний выход

    OpenDoor(); // Основная логика в конце, без отступов.
}
```

## 4. Практика

### Задание 4.1.1: Тернарная магия
Перепиши этот код в одну строку используя `?:`

```csharp
int score = 75;
string grade;
if (score > 90) grade = "A";
else grade = "B";
```

---

## 5. Резюме
*   `if-else if-else` — база.
*   `?:` — для краткости при присваивании.
*   Избегай вложенности, используй `return` для проверок.
