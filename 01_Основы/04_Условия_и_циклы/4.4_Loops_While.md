# 4.4. Циклы: While и Do-While

Используй их, когда **не знаешь заранее**, сколько раз нужно повторить (например, "пока игрок не умрет" или "пока пользователь не введет правильный пароль").

---

## 1. Цикл while (Пока)

Проверяет условие **ПЕРЕД** выполнением.

```csharp
int hp = 100;

while (hp > 0)
{
    Console.WriteLine($"Жив! HP: {hp}");
    hp -= 10; // Важно! Нужно менять условие, иначе цикл будет вечным.
}
Console.WriteLine("Помер.");
```

Если `hp` изначально 0, цикл не выполнится ни разу.

---

## 2. Цикл do-while (Сделай ... пока)

Проверяет условие **ПОСЛЕ** выполнения.
Гарантирует, что тело цикла выполнится **минимум 1 раз**.

```csharp
string password;
do
{
    Console.Write("Введите пароль: ");
    password = Console.ReadLine();
} 
while (password != "secret");

Console.WriteLine("Доступ разрешен!");
```

Здесь `do-while` идеален, потому что мы должны спросить пароль хотя бы один раз, прежде чем проверять его.

---

## 3. Опасность: Бесконечный цикл

```csharp
while (true)
{
    Console.WriteLine("Я завис...");
}
```
Если ты случайно написал такое, программа "повиснет" и перестанет отвечать. В играх (Unity/Godot) это приведет к зависанию редактора.

---

## 4. Практика

### Задание 4.4.1: Угадай число
1.  Загадай число (например, 42).
2.  В цикле `while` спрашивай у пользователя ввод (`Console.ReadLine`).
3.  Если число меньше — пиши "Мало".
4.  Если больше — "Много".
5.  Если угадал — выходи из цикла.

---

## 5. Резюме
*   `while` — сначала проверка, потом действие.
*   `do-while` — сначала действие, потом проверка (минимум 1 проход).
