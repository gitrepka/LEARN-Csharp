# 4.5. Управление циклом: Break, Continue, Return

Иногда нужно прервать цикл досрочно или пропустить один шаг.

---

## 1. break (Выход)

Мгновенно прерывает **текущий** цикл. Управление переходит к строке после цикла.

```csharp
// Ищем число 7
for (int i = 0; i < 100; i++)
{
    if (i == 7)
    {
        Console.WriteLine("Нашел!");
        break; // Остальные 92 итерации не нужны. Выходим.
    }
}
```

---

## 2. continue (Пропуск)

Мгновенно переходит к **следующей итерации**. Код ниже `continue` в этот раз не выполняется.

```csharp
// Выводим только нечетные
for (int i = 0; i < 10; i++)
{
    if (i % 2 == 0) 
    {
        continue; // Это четное? Пропускаем!
    }
    
    Console.WriteLine(i); // Сработает только для 1, 3, 5...
}
```

---

## 3. return (Возврат)

Выходит не просто из цикла, а **из всего метода**.

```csharp
void FindAndPrint(string[] names, string target)
{
    foreach (var name in names)
    {
        if (name == target)
        {
            Console.WriteLine("Found it!");
            return; // Метод завершен. Конец.
        }
    }
    
    Console.WriteLine("Not found..."); // Выполнится, только если return не сработал.
}
```

## 4. Практика

### Задание 4.5.1: Фильтр
Есть массив: `int[] nums = { 5, -2, 10, 0, -5, 20 };`
1.  Перебери его циклом.
2.  Если число отрицательное — используй `continue` (пропусти).
3.  Если число равно 0 — используй `break` (останови перебор).
4.  Выводи остальные числа.
   *(Ожидаемый вывод: 5, 10)*
