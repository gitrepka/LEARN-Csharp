# 4.3. Циклы: For и Foreach

Компьютеры хороши тем, что могут делать одно и то же миллиард раз, не уставая.

---

## 1. Цикл for (Счетчик)

Классика. Используй, когда знаешь, **сколько раз** нужно повторить.

```csharp
// (Инициализация; Условие; Шаг)
for (int i = 0; i < 5; i++)
{
    Console.WriteLine($"Итерация {i}");
}
```
*Результат:* 0, 1, 2, 3, 4.

### Обратный отсчет
```csharp
for (int i = 10; i >= 0; i--) { ... }
```

### Шаг 2
```csharp
for (int i = 0; i < 10; i += 2) { ... } // 0, 2, 4, 6, 8
```

---

## 2. Цикл foreach (Перебор)

Лучший выбор для **массивов и списков**.
Ты говоришь: "Дай мне каждую вещь из этой кучи по очереди".

```csharp
string[] names = { "Alex", "Bob", "Clara" };

foreach (string name in names)
{
    Console.WriteLine($"Hello, {name}!");
}
```

### Преимущества foreach:
1.  **Нельзя выйти за границы массива.** (`IndexOutOfRangeException` невозможен).
2.  **Чище код.** Нет `i`, `names[i]`.
3.  **Безопасность.** Внутри foreach нельзя менять саму коллекцию (удалять элементы), но можно менять свойства объектов внутри.

## 4. Резюме
*   `for` — когда нужен индекс (i) или сложный шаг.
*   `foreach` — для перебора всех элементов коллекции. (Используй его в 90% случаев).
