# 7.3. Ref, Out, In: Управление ссылками

Помнишь тему 2.1 (Стек и Куча)? По умолчанию значимые типы (`int`, `bool`) передаются в метод **копированием**.
Если ты изменишь `int x` внутри метода, снаружи он останется прежним.
Но иногда нужно изменить оригинал. Для этого есть три ключевых слова.

---

## 1. ref (Вход и Выход)

Передает переменную **по ссылке**. Метод работает с оригиналом.

```csharp
static void Increment(ref int n)
{
    n++; // Меняем оригинал
}

int myNumber = 10;
Increment(ref myNumber); // Нужно писать ref и тут!
Console.WriteLine(myNumber); // Выведет 11
```
*Важно:* Переменная должна быть инициализирована (ей должно быть присвоено значение) до вызова.

---

## 2. out (Только Выход)

Похож на `ref`, но используется, когда метод должен **вернуть больше одного значения**.

```csharp
static void GetPlayerStats(out int hp, out int mp)
{
    // Внутри метода ОБЯЗАТЕЛЬНО нужно присвоить значения out-параметрам
    hp = 100;
    mp = 50;
}

int health, mana;
GetPlayerStats(out health, out mana);
```
Самый частый пример: `int.TryParse("123", out int result)`.

---

## 3. in (Только Вход)

Передает по ссылке, но **запрещает изменять** значение.
Зачем это нужно? Для производительности. Если у тебя огромная структура (`struct`), копировать её в стек — долго. `in` передает просто адрес, экономя время, и гарантирует, что метод не испортит данные.

```csharp
static void PrintLargeData(in long bigNumber)
{
    // bigNumber = 10; // ОШИБКА! Только чтение.
    Console.WriteLine(bigNumber);
}
```

---

## 4. Сводная таблица

| Модификатор | Нужно ли значение ДО? | Нужно ли присвоить ВНУТРИ? | Можно ли менять ВНУТРИ? |
| :--- | :--- | :--- | :--- |
| **(нет)** | Да | Нет | Да (но изменится только копия) |
| **ref** | Да | Нет | Да (изменится оригинал) |
| **out** | Нет | **Да (обязательно)** | Да (изменится оригинал) |
| **in** | Да | Нет | **Нет** |

## 5. Практика

### Задание 7.3.1: Метод Swap
Напиши метод `static void Swap(ref int a, ref int b)`, который меняет значения двух переменных местами.

### Задание 7.3.2: Деление с остатком
Напиши метод `static int Divide(int a, int b, out int remainder)`. Он должен возвращать результат деления, а через `out` отдавать остаток.

---

## 6. Резюме
*   `ref` — меняем оригинал.
*   `out` — возвращаем дополнительные данные.
*   `in` — передаем по ссылке без права менять (для скорости).
