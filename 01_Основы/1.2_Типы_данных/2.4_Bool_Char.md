# 2.4. Логика и Символы

Кроме чисел, компьютеру нужно понимать "Да/Нет" и текст.

---

## 1. Логический тип (bool)

Самый простой тип.
*   **Значения:** Только `true` (истина) или `false` (ложь).
*   **Размер:** 1 байт. (Хотя информации всего 1 бит, процессору неудобно читать меньше байта, поэтому он занимает 8 бит).

```csharp
bool isAlive = true;
bool hasKey = false;
bool canOpenDoor = isAlive && hasKey; // Логика!
```

Никаких `1` или `0` как в C++. В C# `bool` — это отдельный строгий тип. Нельзя написать `if (1)`.

---

## 2. Символьный тип (char)

Хранит **один** символ.
*   **Кавычки:** Обязательно одинарные `'A'`.
*   **Кодировка:** Unicode (UTF-16). Это значит, что он занимает 2 байта и может хранить не только латиницу, но и кириллицу, иероглифы и даже смайлики (некоторые).

### Char — это тоже число
Под капотом `char` — это просто число от 0 до 65535 (код символа).

```csharp
char letter = 'A';
int code = (int)letter; 
Console.WriteLine(code); // Выведет 65 (код буквы A)

char next = (char)(code + 1);
Console.WriteLine(next); // Выведет 'B'
```

### Управляющие символы (Escape sequences)
Иногда нужно записать символ, который нельзя напечатать (например, Enter).
Для этого используется слэш `\`.

*   `'\n'` — новая строка (Enter).
*   `'\t'` — табуляция (Tab).
*   `'\''` — сама одинарная кавычка.
*   `'\\'` — сам слэш.
