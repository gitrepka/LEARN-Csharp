# 2.6. var, const, readonly и default

C# — язык со строгой типизацией. Но иногда можно писать меньше кода.

---

## 1. Ключевое слово var

`var` позволяет компилятору самому угадать тип переменной по её значению.

```csharp
var age = 25;       // Компилятор видит 25 (int) -> age становится int
var name = "Alice"; // Компилятор видит "" (string) -> name становится string
```

### ⚠️ ЭТО НЕ DYNAMIC!
`var` работает только в момент компиляции. После этого переменная становится обычным `int` или `string`.
Ты **не можешь** поменять тип потом:

```csharp
var x = 10;
x = "Hello"; // ОШИБКА! x уже int.
```

### Когда использовать var?
**ДА:** Когда тип очевиден из правой части.
```csharp
var sb = new StringBuilder(); // Ясно, что это StringBuilder
var users = new Dictionary<string, int>(); // Короче, чем писать тип дважды
```

**НЕТ:** Когда тип неясен.
```csharp
var result = GetData(); // Что это? int? string? bool? Приходится наводить мышку.
// Лучше:
int result = GetData();
```

## 2. Константы (const)

Иногда нужно закрепить значение навсегда.

```csharp
const double Pi = 3.14159;
const int MaxLives = 3;
```

**Правила const:**
1.  Обязана быть инициализирована сразу.
2.  Значение должно быть известно **во время компиляции** (число, строка). Нельзя присвоить результат вызова метода.
3.  Её нельзя изменить.

**Зачем?** Чтобы не было "магических чисел" в коде. Вместо `if (lives < 3)` лучше писать `if (lives < MaxLives)`.

## 3. readonly и static readonly

`const` подходит только для значений известных при компиляции. А если значение определяется в runtime?

```csharp
// readonly — устанавливается при создании объекта, потом не меняется
class Player
{
    public readonly int MaxHp;     // задаётся в конструкторе
    public readonly DateTime CreatedAt = DateTime.Now; // или при объявлении

    public Player(int maxHp)
    {
        MaxHp = maxHp; // ✅ Можно в конструкторе
    }

    public void TakeDamage()
    {
        // MaxHp = 200; // ❌ Ошибка! readonly нельзя менять после конструктора
    }
}
```

### static readonly — одно значение на весь класс

```csharp
class GameConfig
{
    public static readonly string Version = "1.0.0";
    public static readonly DateTime LaunchTime = DateTime.Now; // определяется в runtime!
}

// const string Version = DateTime.Now.ToString(); // ❌ const не может — это runtime-значение
```

### Сравнение const vs readonly vs static readonly

| | `const` | `readonly` | `static readonly` |
|---|---------|------------|-------------------|
| Когда задаётся | Компиляция | Конструктор | Статический конструктор / объявление |
| Можно менять? | Нет | Нет (после конструктора) | Нет |
| Runtime-значения? | ❌ | ✅ | ✅ |
| Неявно static? | Да | Нет | Да |

## 4. Значения по умолчанию (default)

У каждого типа есть "пустое" значение.

```csharp
int a = default;       // 0
bool b = default;      // false
string c = default;    // null
```
Это полезно в дженериках (которые мы изучим позже).

## 5. Практика

### Задание 2.6.1: Рефакторинг
Перепиши этот код, используя `var` там, где это уместно, и `const` для магических чисел.

```csharp
int maxSpeed = 100;
string message = "Speed limit exceeded";
Random random = new Random();
int currentSpeed = random.Next(0, 200);

if (currentSpeed > maxSpeed)
{
    Console.WriteLine(message);
}
```

---

## Резюме
- `var` — компилятор выводит тип, но переменная строго типизирована
- `const` — значение известно при компиляции, нельзя менять
- `readonly` — значение задаётся в конструкторе, потом нельзя менять
- `static readonly` — как readonly, но одно на весь класс (для runtime-значений)
- `default` — значение по умолчанию для любого типа
