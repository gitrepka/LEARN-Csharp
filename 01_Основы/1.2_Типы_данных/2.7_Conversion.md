# 2.7. Преобразование типов: Магия трансформации

C# — строгий язык. Он не разрешит тебе просто так положить "большое" в "маленькое" или текст в число. Ты должен явно сказать ему об этом.

---

## 1. Неявное преобразование (Implicit)

Это **безопасное** преобразование. Компилятор делает его сам, потому что данные точно не потеряются.
Правило: **Из маленького -> В большое.**

```csharp
int small = 10;
long big = small; // ✅ Можно! int (2 млрд) легко влезет в long (квинтиллионы).

float f = 3.14f;
double d = f;     // ✅ Можно! У double точность выше.
```

---

## 2. Явное преобразование (Explicit) — Кастинг

Это **опасное** преобразование. Ты говоришь компилятору: *"Я знаю, что делаю, просто отрежь лишнее"*.
Синтаксис: `(тип)значение`.

```csharp
double pi = 3.14159;
int wholePi = (int)pi; // ⚠️ Дробная часть (0.14159) отсекается навсегда!
// wholePi станет 3

long huge = 1000;
int tiny = (int)huge;  // ✅ Влезет.

long monster = 3000000000; // 3 млрд
int broken = (int)monster; // ⚠️ Переполнение! (int макс 2.1 млрд)
// broken станет отрицательным числом из-за битового сдвига.
```

**Важно:** Кастинг `(int)` не округляет число, а просто **отбрасывает** дробную часть.
*   `(int)3.99` превратится в `3`.

---

## 3. Парсинг (Из строки в число)

Если у тебя есть текст `"42"`, кастинг `(int)"42"` не сработает. Строка и число — это абсолютно разные вещи в памяти.
Нужно "распрасить" (прочитать) строку.

### Способ А: int.Parse()
```csharp
string text = "100";
int number = int.Parse(text); // 100
```
⚠️ **Опасно:** Если в строке мусор (`"100abc"`), программа упадет с ошибкой `FormatException`.

### Способ Б: Convert.ToInt32()
Похож на Parse, но спокойнее относится к `null` (вернет 0).
```csharp
string empty = null;
int num = Convert.ToInt32(empty); // 0
```
*Заметка:* `ToInt32` — это и есть `int`. `ToInt64` — это `long`.

### Способ В: int.TryParse() — Безопасный выбор
Используется в реальных приложениях, чтобы программа не падала при вводе пользователя.
```csharp
string input = "bad data";
int result;
bool success = int.TryParse(input, out result);

if (success)
    Console.WriteLine($"Число: {result}");
else
    Console.WriteLine("Это не число!");
```

## 4. Класс BitConverter (Для хакеров)
Иногда нужно превратить массив байт `byte[]` в число или наоборот.
```csharp
int x = 12345;
byte[] bytes = BitConverter.GetBytes(x); // Превратили число в набор байт
```

## 6. Резюме
*   **Маленькое в большое** — само.
*   **Большое в маленькое** — `(тип)` с потерей данных.
*   **Строка в число** — `Parse` или `TryParse`.
