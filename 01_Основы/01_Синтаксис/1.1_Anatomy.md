# 1.1. Анатомия программы

## Введение
Прежде чем писать код, нужно понять, как он живет. Мы часто думаем, что код — это просто инструкции для процессора. Но в мире C# это чуть сложнее и интереснее.

В этом уроке мы разберем "жизненный цикл" программы и её точку входа.

---

## 1. Путь кода: От текста до процессора

Ты написал `Console.WriteLine("Hello");`. Что происходит дальше?

### Шаг 1: Компиляция (Roslyn)
Твой код (`.cs`) читает **Компилятор**. Он проверяет синтаксис (не забыл ли ты точку с запятой).
Если всё ок, он превращает код не в машинный код, а в **IL (Intermediate Language)**.
*   *Аналогия:* Ты написал книгу на русском. Редактор перевел её на эсперанто (IL). Этот язык понимают все .NET-системы, но не твой процессор.
*   *Результат:* Файл `.dll` или `.exe`.

### Шаг 2: CLR (Common Language Runtime)
Когда ты запускаешь программу, просыпается **CLR** — виртуальная машина .NET. Она берет твой IL-код.

### Шаг 3: JIT (Just-In-Time Compilation)
CLR видит, что ты хочешь запустить метод `Main`. Она вызывает **JIT-компилятор**.
JIT берет IL-код метода `Main` и прямо "на лету" переводит его в **Машинный код** (нули и единицы), понятный именно твоему процессору (Intel, AMD, ARM).
*   *Аналогия:* Переводчик читает книгу на эсперанто и вслух переводит её читателю на его родной язык.

### Зачем так сложно?
Почему не сразу в машинный код?
1.  **Кроссплатформенность:** Один и тот же `.dll` с IL-кодом можно запустить и на Windows, и на Linux, и на Mac. JIT сам разберется, какой процессор стоит на машине.
2.  **Оптимизация:** JIT видит, какой именно у тебя процессор, и может использовать его скрытые фишки для ускорения.

## 2. Точка входа: Main

Любая программа должна с чего-то начаться. В C# это метод `Main`.

### Вариант А: Классический (до C# 9)
Так выглядят миллионы строк старого кода. Ты обязан это знать.

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        // static - метод принадлежит классу, а не объекту
        // void - метод ничего не возвращает (просто делает дело)
        // string[] args - параметры запуска из командной строки
        static void Main(string[] args)
        {
            Console.WriteLine("Привет, классика!");
        }
    }
}
```

### Вариант Б: Top-Level Statements (C# 9+)
Компилятор стал умнее. Он говорит: "Если ты просто пишешь код в файле, я сам пойму, что это Main".

```csharp
// Program.cs
Console.WriteLine("Привет, современность!");
```

**Что происходит под капотом?**
Компилятор молча создает класс `Program` и метод `Main` и помещает твой код туда. Это "синтаксический сахар".

**Правила Top-Level Statements:**
1.  Могут быть только в **ОДНОМ** файле проекта (обычно `Program.cs`).
2.  Должны идти **до** любых объявлений классов или методов в этом файле.

## 4. Резюме
*   Код C# проходит путь: **C# -> IL -> (JIT) -> Native Code**.
*   **CLR** — это среда, где живет твоя программа.
*   **Top-Level Statements** — это просто сокращение для метода `Main`.
