# 10.1. Глобализация: CultureInfo

Мир разный. В России разделитель в числах — запятая (`3,14`), в США — точка (`3.14`). Если ты сохранишь настройки игры на русском компьютере, а потом запустишь на американском — она может упасть.

---

## 1. Что такое CultureInfo?

Это объект, который содержит все правила страны: валюту, формат дат, разделители.

```csharp
using System.Globalization;

// Культура США
CultureInfo us = new CultureInfo("en-US");
// Культура России
CultureInfo ru = new CultureInfo("ru-RU");

double price = 1234.56;

Console.WriteLine(price.ToString(us)); // 1,234.56
Console.WriteLine(price.ToString(ru)); // 1 234,56
```

---

## 2. InvariantCulture (Инвариантная культура)

Это "технический стандарт". Он основан на английском языке, но не привязан к стране.
**Золотое правило:**
*   Когда показываешь данные **человеку** — используй его культуру (`CurrentCulture`).
*   Когда записываешь данные в **файл, базу данных или логи** — ВСЕГДА используй `CultureInfo.InvariantCulture`.

```csharp
// Записываем в файл (всегда будет с точкой)
string dataForFile = price.ToString(CultureInfo.InvariantCulture);
```

---

## 3. Глобальная смена культуры

Ты можешь заставить все приложение работать на одном языке:
```csharp
CultureInfo.DefaultThreadCurrentCulture = new CultureInfo("en-US");
```
