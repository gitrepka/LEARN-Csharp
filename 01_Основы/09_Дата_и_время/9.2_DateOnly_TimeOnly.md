# 9.2. DateOnly и TimeOnly: Точечная точность

До .NET 6 у нас был только `DateTime`, который всегда таскал с собой и дату, и время. Но для дня рождения часы не нужны, а для расписания уроков не важна дата.

---

## 1. DateOnly (.NET 6+)

Хранит только Год, Месяц и День.

```csharp
DateOnly birthday = new DateOnly(2000, 1, 1);
Console.WriteLine(birthday); // 01.01.2000
```
Это экономит память и избавляет от глупых ошибок, когда "01.01.2000 00:00:01" не равно "01.01.2000 00:00:00".

---

## 2. TimeOnly (.NET 6+)

Хранит только время (от 00:00:00 до 23:59:59).

```csharp
TimeOnly alarmClock = new TimeOnly(7, 30); // 07:30 утра
```
Удобно для расписаний, таймеров и графиков работы.

---

## 3. Преобразование

```csharp
DateTime now = DateTime.Now;

// Достаем только дату
DateOnly d = DateOnly.FromDateTime(now);

// Достаем только время
TimeOnly t = TimeOnly.FromDateTime(now);
```

## 5. Резюме
*   Нужен день рождения? -> `DateOnly`.
*   Нужен будильник? -> `TimeOnly`.
*   Нужен момент в истории? -> `DateTime`.
