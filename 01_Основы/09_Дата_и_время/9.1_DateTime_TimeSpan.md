# 9.1. DateTime и TimeSpan: Измерение времени

Время в программировании — штука капризная (високосные годы, часовые пояса). C# берет большую часть забот на себя.

---

## 1. DateTime

Хранит конкретный момент времени (Дата + Часы/Минуты/Секунды).

```csharp
DateTime now = DateTime.Now; // Текущее время компьютера
DateTime graduation = new DateTime(2026, 6, 20); // Своя дата
```

### Главный совет: Используй UTC!
Если твоя программа работает в интернете, `DateTime.Now` — это зло. У тебя в Москве один час, у пользователя в Нью-Йорке другой. Сервер запутается.
Всегда храни время в **UTC** (универсальное время), а в местное превращай только при показе пользователю.

```csharp
DateTime serverTime = DateTime.UtcNow;
```

---

## 2. TimeSpan

Это не дата, это **промежуток** (длительность).

```csharp
TimeSpan duration = new TimeSpan(2, 30, 0); // 2 часа 30 минут

// Можно складывать и вычитать
DateTime later = DateTime.Now + duration;

// Разница между датами — это тоже TimeSpan
TimeSpan howLong = graduation - DateTime.Now;
Console.WriteLine($"До выпуска осталось {howLong.Days} дней");
```

---

## 3. Свойства DateTime
*   `Now.DayOfWeek` — какой сегодня день (Monday, Tuesday...).
*   `Now.Year` — текущий год.
*   `Now.AddDays(10)` — какая дата будет через 10 дней.
