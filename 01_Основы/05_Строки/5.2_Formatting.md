# 5.2. Форматирование и Интерполяция

Выводить данные в консоль или UI нужно красиво. Просто `+` не всегда удобно.

---

## 1. Интерполяция строк ($) — Современный стандарт

Ставишь `$` перед кавычками, и можешь писать переменные прямо внутри `{}`.

```csharp
string name = "Aibek";
int score = 42;
Console.WriteLine($"Player {name} has score: {score}");
```
Это читается гораздо легче, чем `+ " " +`.

---

## 2. Форматирование чисел

Внутри `{}` после двоеточия можно указать **код формата**.

### Деньги (:C)
Автоматически добавляет знак валюты (рубль, доллар — зависит от настроек Windows).
```csharp
decimal price = 150.99m;
Console.WriteLine($"Цена: {price:C}"); // Цена: 150,99 ₽
```

### Числа с запятой (:F или :N)
Ограничивает количество знаков после запятой.
```csharp
double pi = 3.14159265;
Console.WriteLine($"{pi:F2}"); // 3,14
```

### Шестнадцатеричный код (:X)
Часто используется в GameDev для цветов (Hex).
```csharp
int color = 255;
Console.WriteLine($"Hex: {color:X2}"); // FF
```

---

## 3. Вертикальное выравнивание (Alignment)

Если нужно вывести таблицу в консоль, можно указать ширину колонки через запятую: `{переменная, ширина}`.

```csharp
Console.WriteLine($"{"Name",-10} | {"Score",5}");
Console.WriteLine($"{"Alex",-10} | {1500,5}");
Console.WriteLine($"{"Bob",-10} | {42,5}");
```
*   `10` — колонка шириной 10 символов.
*   `-` (минус) — выравнивание по **левому** краю.

---

## 4. Raw String Literals (C# 11+)

Если тебе нужно написать многострочный текст (например, JSON или XML), используй тройные кавычки `"""`.

```csharp
string json = """
{
  "name": "Player",
  "level": 10
}
""";
```
Они сохраняют отступы и переносы строк именно так, как ты их написал.

---

## 6. Резюме
*   `$""` — основной способ сборки строк.
*   `:C`, `:F2`, `:X2` — самые частые форматтеры.
*   `"""` — для больших кусков текста.
