# 5.3. StringBuilder: Секрет производительности

Помнишь, в теме 2.5 мы говорили, что строки **неизменяемы (Immutable)**? 
Это ведет к большой проблеме, если тебе нужно склеить много строк.

---

## 1. В чем проблема?

Представь такой код:
```csharp
string s = "";
for (int i = 0; i < 10000; i++)
{
    s += i.ToString(); // ПЛОХО!
}
```

**Что происходит в памяти:**
1. На каждой итерации выделяется **новое** место в Куче (Heap).
2. Старая строка копируется в новую.
3. Старая строка выбрасывается (нагрузка на Garbage Collector).
Для 10,000 итераций ты создашь 10,000 лишних строк. Программа начнет тормозить и "жрать" память.

---

## 2. Решение: StringBuilder

`StringBuilder` — это специальный "конструктор" строк. Он создает внутри себя **буфер** (массив), в который просто дописывает данные, не пересоздавая объект.

```csharp
using System.Text; // Нужно подключить это пространство!

var sb = new StringBuilder();

for (int i = 0; i < 10000; i++)
{
    sb.Append(i); // Копирования не происходит! Просто дописываем в конец.
}

string result = sb.ToString(); // Только в самом конце создаем одну итоговую строку.
```

### Когда использовать?
*   Если склеиваешь больше 5-10 строк в одном месте.
*   Если работаешь внутри любого цикла (`for`, `while`).

---

## 3. Основные методы

*   `Append(val)` — добавить в конец.
*   `AppendLine(val)` — добавить строку и перенос (Enter).
*   `Insert(index, val)` — вставить в середину.
*   `Clear()` — очистить всё (удобно для переиспользования одного StringBuilder).

## 5. Резюме
*   `string` — для одиночных операций.
*   `StringBuilder` — для массовой сборки текста и циклов.
*   Экономит память и время процессора в десятки раз.
