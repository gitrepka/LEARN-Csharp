# 5.4. Регулярные выражения (Regex)

Иногда методы строк пасуют. Как проверить, что пользователь ввел настоящий Email? Или вытащить из текста все номера телефонов? 
Для этого нужны **регулярные выражения** — язык описания шаблонов.

---

## 1. Основы синтаксиса шаблонов

*   `\d` — любая цифра (0-9).
*   `\w` — любая буква или цифра.
*   `\s` — пробел.
*   `+` — один или более (например, `\d+` — это целое число).
*   `*` — ноль или более.
*   `.` — вообще любой символ.
*   `^` — начало строки, `$` — конец.

---

## 2. Использование в C#

```csharp
using System.Text.RegularExpressions;

string input = "Contact us at 123-456-789 or 987-654-321";
string pattern = @"\d{3}-\d{3}-\d{3}"; // Шаблон телефона

// 1. Простая проверка
bool isMatch = Regex.IsMatch(input, pattern);

// 2. Поиск всех совпадений
MatchCollection matches = Regex.Matches(input, pattern);
foreach (Match m in matches)
{
    Console.WriteLine($"Found: {m.Value}");
}
```

---

## 3. Современный подход: Source Generators (C# 11+)

Обычный `Regex` медленный, потому что компилируется во время работы программы. В современном C# используют атрибут `[GeneratedRegex]`, который создает быстрый код еще на этапе написания программы.

```csharp
// Это требует partial класса
public partial class Validator
{
    [GeneratedRegex(@"^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$")]
    public static partial Regex EmailRegex();

    public bool IsValid(string email) => EmailRegex().IsMatch(email);
}
```
