# 5.1. Методы строк: Хирургия текста

В реальных программах (особенно в играх и бизнес-софте) 50% времени мы работаем с текстом. Нужно уметь делать это быстро и без ошибок.

---

## 1. Поиск и Проверка

### Содержит ли строка подстроку?
```csharp
string text = "Hello, C# Developer!";

bool hasCSharp = text.Contains("C#"); // true
bool startsWithHello = text.StartsWith("Hello"); // true
bool endsWithExcl = text.EndsWith("!"); // true
```

### Где находится символ?
```csharp
int index = text.IndexOf("#"); // 8 (индексы начинаются с 0)
int lastIndex = text.LastIndexOf("e"); // 17 (последнее вхождение)
```
*Если символ не найден, вернет -1.*

---

## 2. Модификация (Помни: создается НОВАЯ строка!)

### Регистр
```csharp
string lower = text.ToLower(); // всё маленькими
string upper = text.ToUpper(); // всё КАПСОМ
```

### Удаление лишнего (Trim)
Полезно при вводе пароля или почты пользователем.
```csharp
string input = "  admin@mail.com  ";
string clean = input.Trim(); // "admin@mail.com" (удаляет пробелы с краев)
```

### Замена
```csharp
string newText = text.Replace("C#", "Godot"); // "Hello, Godot Developer!"
```

### Обрезка (Substring)
```csharp
// (с какого индекса, сколько символов)
string sub = text.Substring(7, 2); // "C#"
```

---

## 3. Разделение и Склеивание

### Split (Разбивка на массив)
```csharp
string csv = "Apple,Banana,Orange";
string[] fruits = csv.Split(','); 
// fruits[0] = "Apple", fruits[1] = "Banana"...
```

### Join (Сборка массива в строку)
```csharp
string backTogether = string.Join(" | ", fruits);
// "Apple | Banana | Orange"
```

## 5. Резюме
*   `Contains`, `StartsWith` — для проверок.
*   `Trim`, `Replace`, `Substring` — для правок.
*   `Split` и `Join` — для работы со списками слов.
