# 4.2. Switch: Пульт управления

Когда условий много (`if (a==1) ... else if (a==2) ...`), код превращается в лапшу. `switch` делает его структурированным.

---

## 1. Классический switch (Statement)

```csharp
int direction = 1; // 0-Up, 1-Right, 2-Down, 3-Left

switch (direction)
{
    case 0:
        Console.WriteLine("Вверх");
        break; // Обязательно! Иначе ошибка.
    case 1:
        Console.WriteLine("Вправо");
        break;
    case 2:
    case 3: // Группировка (для 2 и 3 одно действие)
        Console.WriteLine("Вниз или Влево");
        break;
    default: // Если ничего не подошло
        Console.WriteLine("Стоим");
        break;
}
```

---

## 2. Современный Switch Expression (C# 8+) — 🚀

Это выражение. Оно **возвращает** результат. Выглядит лаконично.

```csharp
var key = Console.ReadKey().Key;

string action = key switch
{
    ConsoleKey.W => "Move Up",
    ConsoleKey.S => "Move Down",
    ConsoleKey.A => "Move Left",
    ConsoleKey.D => "Move Right",
    _ => "Idle" // _ это аналог default
};
```

### С условиями (When)
Можно добавлять логику в кейсы.

```csharp
int score = 85;

string rank = score switch
{
    >= 90 => "Legend",
    >= 80 => "Master",
    >= 50 => "Pro",
    _ => "Noob"
};
```

---

## 3. Pattern Matching (Введение)

Switch умеет проверять не только значения, но и типы.

```csharp
object obj = 42;

switch (obj)
{
    case int i:
        Console.WriteLine($"Это число: {i}");
        break;
    case string s:
        Console.WriteLine($"Это строка длиной {s.Length}");
        break;
    case null:
        Console.WriteLine("Ничего нет");
        break;
}
```

## 4. Практика

### Задание 4.2.1: Калькулятор 2.0
Напиши метод `Calculate(double a, double b, char op)`, который использует **switch expression**.
*   Если `op` == `+`, верни a + b.
*   Если `-`, a - b.
*   Если `/`, деление (проверь на 0!).
*   Иначе выбрось исключение или верни NaN.

---

## 5. Резюме
*   Используй `switch expression` (со стрелочками `=>`) для присваивания значений.
*   Используй классический `switch`, если нужно выполнять много действий в каждом кейсе.
*   `_` (подчеркивание) — это `default`.
