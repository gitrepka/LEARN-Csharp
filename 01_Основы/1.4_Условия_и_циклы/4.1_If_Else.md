# 4.1. if / else if / else

## Что ты узнаешь
- Условный оператор `if`
- Цепочка `else if`
- Блок `else`
- Вложенные условия

> switch → 4.2, циклы → 4.3/4.4, break/continue/return → 4.5

---

## ЗАЧЕМ?
Без условий программа — просто список инструкций сверху вниз. С ними она умеет ДУМАТЬ. "Если враг рядом — атакуй. Иначе — патрулируй."

## Условный оператор if

```csharp
int health = 30;

if (health > 75)
{
    Console.WriteLine("Полное здоровье");
}
```

Если условие `true` — код внутри `{}` выполняется. Если `false` — пропускается.

## else — что делать если условие не выполнено

```csharp
int health = 30;

if (health > 50)
{
    Console.WriteLine("Здоров");
}
else
{
    Console.WriteLine("Ранен"); // ← этот вариант
}
```

## else if — цепочка условий

```csharp
int health = 30;

if (health > 75)
{
    Console.WriteLine("Полное здоровье");
}
else if (health > 25)
{
    Console.WriteLine("Ранен");
}
else
{
    Console.WriteLine("При смерти!"); // ← этот вариант
}
```

Порядок важен! C# проверяет условия **сверху вниз** и выполняет ПЕРВОЕ подходящее.

## Вложенные условия

```csharp
bool hasWeapon = true;
int ammo = 0;

if (hasWeapon)
{
    if (ammo > 0)
    {
        Console.WriteLine("Стреляй!");
    }
    else
    {
        Console.WriteLine("Оружие есть, но патронов нет");
    }
}
else
{
    Console.WriteLine("Безоружен");
}
```

**Совет:** Старайся не делать вложенность больше 2-3 уровней — код становится нечитаемым.

## Однострочный if (без скобок)

```csharp
if (health <= 0)
    Console.WriteLine("Мёртв");

// НО! Если нужно больше одной строки — скобки ОБЯЗАТЕЛЬНЫ
if (health <= 0)
{
    Console.WriteLine("Мёртв");
    PlayDeathAnimation();
}
```

**Рекомендация:** Всегда ставь `{}`, даже для одной строки — меньше ошибок.

## Частые ошибки

### 1. = вместо ==
```csharp
// ❌ Присваивание, а не сравнение!
// if (x = 5) { }  // Ошибка компиляции в C# (спасибо, компилятор!)

// ✅ Двойное равно:
if (x == 5) { }
```

### 2. Пропущенные скобки
```csharp
// ❌ Только первая строка в if, вторая выполнится ВСЕГДА
if (health <= 0)
    Console.WriteLine("Мёртв");
    RespawnPlayer();  // ← выполнится всегда, не только при health <= 0!

// ✅ Скобки:
if (health <= 0)
{
    Console.WriteLine("Мёртв");
    RespawnPlayer();
}
```

### 3. Неправильный порядок else if
```csharp
int score = 95;

// ❌ Первое условие поглощает все остальные:
if (score > 50)
    Console.WriteLine("Удовл"); // 95 > 50 → true, сюда попадёт!
else if (score > 75)
    Console.WriteLine("Хорошо"); // до сюда не дойдёт
else if (score > 90)
    Console.WriteLine("Отлично"); // и до сюда

// ✅ От большего к меньшему:
if (score > 90)
    Console.WriteLine("Отлично"); // ← правильно!
else if (score > 75)
    Console.WriteLine("Хорошо");
else if (score > 50)
    Console.WriteLine("Удовл");
```

## Мини-упражнения

1. **⭐** Напиши программу: пользователь вводит число, выведи "Положительное", "Отрицательное" или "Ноль".
2. **⭐** Определи по возрасту категорию: ребёнок (0-12), подросток (13-17), взрослый (18-64), пенсионер (65+).
3. **⭐** Напиши проверку: если `username` не пустой И `password.Length >= 8` — "Вход разрешён", иначе — покажи конкретную ошибку.
