# 8.1. Регулярные выражения: Язык шаблонов

Regex (Regular Expressions) — это мощный инструмент для поиска и обработки текста. Если обычный `Contains` ищет конкретное слово, то Regex ищет **паттерн** (шаблон).

---

## 1. Зачем это нужно?
*   Проверить, что Email введен правильно.
*   Найти в тексте все номера телефонов разных форматов.
*   Удалить из текста все лишние пробелы.

---

## 2. Алфавит Regex (Метасимволы)

*   `\d` — любая цифра.
*   `\D` — НЕ цифра.
*   `\w` — любая буква или цифра.
*   `\s` — пробел или перенос строки.
*   `.` — вообще любой символ.
*   `^` — начало строки.
*   `$` — конец строки.

### Квантификаторы (Сколько раз?)
*   `*` — 0 или более раз.
*   `+` — 1 или более раз.
*   `?` — 0 или 1 раз (необязательно).
*   `{n}` — ровно `n` раз.
*   `{n,m}` — от `n` до `m` раз.

---

## 3. Использование в C#

```csharp
using System.Text.RegularExpressions;

string text = "Мой номер: 8-900-123-45-67";
string pattern = @"\d-\d{3}-\d{3}-\d{2}-\d{2}";

if (Regex.IsMatch(text, pattern))
{
    Console.WriteLine("Номер найден!");
}
```
*Совет:* Всегда ставь `@` перед строкой шаблона, чтобы не экранировать слэши.
