# 11.1. Узлы и Сцены: Анатомия игры

Godot отличается от других движков своей простотой и логикой. Главное правило: **Всё есть Узел (Node)**.

---

## 1. Сцены и Дерево
*   **Узел (Node)**: Маленький кирпичик. Один узел умеет показывать спрайт, другой — проигрывать звук, третий — просчитывать физику.
*   **Сцена**: Набор узлов. Сценой может быть Игрок, Враг или целый Уровень.
*   **Дерево сцен (Scene Tree)**: Вся твоя игра — это дерево. В корне — Главная сцена, внутри неё — уровни, в них — игроки и т.д.

---

## 2. Жизненный цикл скрипта

В Godot твой C# класс наследуется от типа узла (например, `Sprite2D` или `Node2D`). У него есть встроенные методы, которые движок вызывает сам:

```csharp
using Godot;

public partial class MySprite : Sprite2D
{
    // Вызывается один раз, когда узел появился в игре
    public override void _Ready()
    {
        GD.Print("Я родился!");
    }

    // Вызывается КАЖДЫЙ КАДР (обычно 60 раз в секунду)
    // delta - это время в секундах, прошедшее с прошлого кадра
    public override void _Process(double delta)
    {
        // Здесь мы обычно двигаем объекты или проверяем ввод
        Rotation += (float)delta; // Вращаем спрайт
    }
}
```

---

## 3. Координаты (2D)
*   **X**: Вправо (увеличивается), Влево (уменьшается).
*   **Y**: **Вниз** (увеличивается!), Вверх (уменьшается). Это важно запомнить.

## 4. Практика: Первая анимация кодом

### Задание 11.1.1
1. Создай новую сцену в Godot. Добавь узел `Sprite2D`.
2. Создай для него C# скрипт.
3. В методе `_Process` напиши код, который двигает спрайт вправо на 100 пикселей в секунду.
   *Подсказка:* `Position += new Vector2(100 * (float)delta, 0);`

---

## 5. Резюме
*   Игра — это дерево узлов.
*   `_Ready` — для настройки (инициализации).
*   `_Process` — для обновления каждый кадр.
*   `delta` — делает движение плавным и независимым от мощности компьютера.
