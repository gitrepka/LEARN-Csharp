# 11.4. Ввод и Физика: Твой первый контроллер

Пора заставить персонажа ходить. В Godot 4 для этого используется мощный узел `CharacterBody2D`.

---

## 1. Input Map (Карта ввода)
Вместо того чтобы проверять "Нажата ли кнопка W", мы проверяем "Нажато ли действие *Вперед*". 
Настрой действия в `Project -> Project Settings -> Input Map` (например, создай действия "ui_left", "ui_right", "ui_up").

---

## 2. Код движения

```csharp
public partial class Player : CharacterBody2D
{
    [Export] public float Speed = 300.0f;
    [Export] public float JumpVelocity = -400.0f;

    // Гравитация из настроек проекта
    public float gravity = ProjectSettings.GetSetting("physics/2d/default_gravity").AsSingle();

    public override void _PhysicsProcess(double delta)
    {
        Vector2 velocity = Velocity;

        // 1. Добавляем гравитацию, если мы не на полу
        if (!IsOnFloor())
            velocity.Y += gravity * (float)delta;

        // 2. Прыжок
        if (Input.IsActionJustPressed("ui_accept") && IsOnFloor())
            velocity.Y = JumpVelocity;

        // 3. Получаем направление ввода (-1, 0, 1)
        float direction = Input.GetAxis("ui_left", "ui_right");
        
        if (direction != 0)
            velocity.X = direction * Speed;
        else
            velocity.X = Mathf.MoveToward(Velocity.X, 0, Speed);

        // Применяем скорость и обрабатываем столкновения
        Velocity = velocity;
        MoveAndSlide(); 
    }
}
```

---

## 3. MoveAndSlide() — Магия физики
Этот метод делает всё за тебя:
*   Двигает тело с заданной скоростью (`Velocity`).
*   Проверяет столкновения со стенами.
*   Позволяет скользить вдоль препятствий.
*   Определяет, стоишь ли ты на полу (`IsOnFloor()`).

## 4. Практика: Платформер

### Задание 11.4.1
1. Создай `StaticBody2D` (Пол) с `CollisionShape2D` (прямоугольник).
2. Создай `CharacterBody2D` (Игрок) со спрайтом и коллизией.
3. Примени код из урока.
4. Настрой `JumpVelocity` и `Speed` через инспектор Godot так, чтобы прыжок ощущался приятно.

---

## 5. Резюме
*   `Input.GetAxis` — лучший способ получить направление движения.
*   `_PhysicsProcess` — место для всей физической логики.
*   `MoveAndSlide()` — база для любого персонажа в 2D.
