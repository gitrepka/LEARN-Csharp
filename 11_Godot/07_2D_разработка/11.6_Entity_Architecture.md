# 11.6. Архитектура: Наследование и Интерфейсы в Игре

Применяем знания ООП (Модуль 2) в игровой среде. Мы создадим структуру, в которой легко добавлять новых врагов и предметы.

---

## 1. Базовый класс для всех существ (Inheritance)

Вместо того чтобы писать код здоровья для каждого врага, создаем общего родителя.

```csharp
public abstract partial class LivingEntity : CharacterBody2D
{
    [Export] public int Health = 100;

    public virtual void TakeDamage(int amount)
    {
        Health -= amount;
        if (Health <= 0) Die();
    }

    protected abstract void Die();
}
```

---

## 2. Интерфейсы для взаимодействий (Polymorphism)

Игрок должен мочь ударить и Врага, и Разрушаемую Бочку. Но Бочка не является `LivingEntity`. Используем интерфейс!

```csharp
public interface IDamageable
{
    void TakeDamage(int amount);
}

// Теперь LivingEntity реализует этот контракт
public abstract partial class LivingEntity : CharacterBody2D, IDamageable { ... }

// И Бочка тоже
public partial class Barrel : StaticBody2D, IDamageable { ... }
```

## 3. Магия C# в бою

```csharp
public void OnSwordHit(Node target)
{
    // Проверяем: "Умеет ли то, по чему мы попали, получать урон?"
    if (target is IDamageable unit)
    {
        unit.TakeDamage(10);
    }
}
```

## 4. Практика: Умный меч
1. Создай интерфейс `IInteractable` с методом `Interact()`.
2. Реализуй его в классах `Door`, `Chest` и `NPC`.
3. В скрипте игрока при нажатии кнопки "E" проверяй через `is IInteractable`, можно ли взаимодействовать с объектом перед собой.
*Здесь ты практикуешь: Интерфейсы, Pattern Matching (is) и абстрактные классы.*

## 5. Резюме
*   **Наследование** — для сокращения кода (общие свойства).
*   **Интерфейсы** — для связи разных систем.
*   Игра превращается в набор объектов, которые общаются друг с другом через строгие контракты C#.
