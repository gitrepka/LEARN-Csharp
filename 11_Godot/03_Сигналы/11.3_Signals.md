# 11.3. Сигналы: Когда что-то произошло

Сигналы — это способ, которым узлы в Godot общаются друг с другом. Это встроенные события движка.

---

## 1. Встроенные сигналы
У каждого узла есть свои сигналы. Например, у Кнопки есть сигнал `Pressed`.
Ты можешь подключить его в коде:

```csharp
public override void _Ready()
{
    Button myBtn = GetNode<Button>("MyButton");
    myBtn.Pressed += OnMyButtonPressed; // Подписка как на обычное событие
}

private void OnMyButtonPressed()
{
    GD.Print("Кнопка нажата в коде!");
}
```

---

## 2. Создание своего сигнала в C#
Чтобы создать свой сигнал, нужно использовать делегат с атрибутом `[Signal]` и суффиксом `EventHandler`.

```csharp
public partial class Player : CharacterBody2D
{
    [Signal]
    public delegate void HealthChangedEventHandler(int oldHp, int newHp);

    public void TakeDamage(int damage)
    {
        int old = Health;
        Health -= damage;
        // Излучаем сигнал
        EmitSignal(SignalName.HealthChanged, old, Health);
    }
}
```

---

## 3. Зачем это нужно?
Это позволяет избежать жесткой зависимости. Скрипт Игрока не должен знать про скрипт Здоровья в UI. Игрок просто излучает сигнал "Здоровье изменилось", а UI-полоска (ProgressBar) ловит его и обновляется.

---

## 5. Резюме
*   Сигналы — это события Godot.
*   `+=` — подписка.
*   `EmitSignal` — отправить уведомление.
*   `SignalName` — статический класс, создаваемый Godot для удобного доступа к именам сигналов.
