# 2.2. Целые числа: Зоопарк типов

В математике целые числа бесконечны. В компьютере — нет. У каждого типа есть предел, зависящий от количества бит.

---

## 1. Основные типы

### byte / sbyte (8 бит)
Самые маленькие.
*   **byte:** 0 ... 255 (Без знака). Часто используется для работы с файлами, цветами (RGB), сетевыми пакетами.
*   **sbyte:** -128 ... 127 (Со знаком). Используется крайне редко.

### short / ushort (16 бит)
*   **short:** -32 768 ... 32 767.
*   **ushort:** 0 ... 65 535.
*   *Где нужны:* В старых API, для экономии памяти в гигантских массивах. В обычной жизни — почти никогда.

### int / uint (32 бита) — КОРОЛЬ ТИПОВ 👑
*   **int:** -2.1 млрд ... +2.1 млрд.
*   **uint:** 0 ... 4.2 млрд.
*   *Где нужны:* **Везде.** Это стандартный тип. Даже если тебе нужно хранить число 5, C# будет использовать `int`, потому что процессоры оптимизированы под 32-битные операции.

### long / ulong (64 бита)
*   **long:** Очень много (±9 квинтиллионов).
*   *Где нужны:* ID в базах данных, подсчет времени (тики), размеры файлов, деньги (иногда, в копейках).
*   **Суффикс:** Чтобы объяснить компилятору, что это long, добавь `L`: `long big = 100L;`.

---

## 2. Переполнение (Overflow) — Опасная зона

Что будет, если к максимальному числу прибавить 1?
`byte b = 255; b++;`

В C# по умолчанию работает **циклическое переполнение** (unchecked).
255 + 1 превратится в **0**.
Аналогично: -128 (минимальный sbyte) минус 1 превратится в +127.

Это может привести к жутким багам (у игрока стало -2 млрд золота).

### Как защититься? (checked)
Можно включить проверку переполнения.

```csharp
checked
{
    int a = int.MaxValue;
    a++; // ВЫБРОСИТ ОШИБКУ: System.OverflowException
}
```

---

## 3. Выбор типа

1.  Нужно целое число? -> **int**.
2.  Число больше 2 миллиардов? -> **long**.
3.  Работаешь с байтами файла/картинки? -> **byte**.
4.  Никогда не используй `unsigned` (uint, ulong) просто чтобы запретить отрицательные числа. Используй их только если нужно работать с битами или внешним API. Почему? Потому что `uint` легче случайно переполнить вниз (0 - 1 = 4 миллиарда).

## 5. Резюме
*   `int` — дефолтный выбор.
*   `L` — суффикс для long.
*   Переполнение молчаливо сбрасывает число в начало. `checked` ловит это.
