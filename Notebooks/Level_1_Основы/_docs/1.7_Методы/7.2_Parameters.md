# 7.2. Параметры: Гибкость и удобство

C# позволяет вызывать методы очень гибко. Тебе не обязательно всегда передавать все аргументы в строгом порядке.

---

## 1. Необязательные параметры (Default values)

Ты можешь задать значение по умолчанию. Если при вызове его не указать, возьмется дефолтное.

```csharp
static void Greet(string name, string message = "Hello")
{
    Console.WriteLine($"{message}, {name}!");
}

Greet("Aibek");            // Hello, Aibek!
Greet("Aibek", "Goodbye"); // Goodbye, Aibek!
```
**Правило:** Необязательные параметры всегда должны стоять в самом конце списка.

---

## 2. Именованные аргументы

Когда параметров много, легко запутаться в их порядке. Ты можешь указывать имена при вызове.

```csharp
static void CreateEmail(string to, string subject, string body) { ... }

// Порядок не важен, если указаны имена
CreateEmail(
    body: "How are you?", 
    to: "test@mail.com", 
    subject: "Hi!"
);
```
Это делает код самодокументируемым.

---

## 3. Массив параметров (params)

Хочешь метод, который принимает любое количество чисел? Используй `params`.

```csharp
static int SumAll(params int[] numbers)
{
    int total = 0;
    foreach (int n in numbers) total += n;
    return total;
}

int s1 = SumAll(1, 2, 3);
int s2 = SumAll(10, 20, 30, 40, 50, 60);
int s3 = SumAll(); // Вернет 0, массив будет пустым
```
**Ограничение:** `params` может быть только один и только последним в списке.

## 4. Практика: Универсальный калькулятор

### Задание 7.2.1
Напиши метод `static double Average(params double[] numbers)`.
* Он должен возвращать среднее арифметическое всех переданных чисел.
* Если чисел нет, пусть возвращает 0.0.
* Вызови его тремя разными способами.

## 5. Резюме
*   `message = "Hi"` — параметр по умолчанию.
*   `name: "Alex"` — именованный вызов.
*   `params` — для переменного количества аргументов.
