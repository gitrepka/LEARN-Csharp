# 6.3. Индексы и Диапазоны (^ и ..)

В C# 8.0 добавили "синтаксический сахар", который делает работу с частями массивов невероятно удобной. Это похоже на Python.

---

## 1. Индексы с конца (^)

Раньше, чтобы взять последний элемент, мы писали: `arr[arr.Length - 1]`.
Теперь есть оператор `^`.

```csharp
int[] numbers = { 10, 20, 30, 40, 50 };

int last = numbers[^1];   // 50 (первый с конца)
int secondLast = numbers[^2]; // 40
```
*Запомни:* `^0` вызовет ошибку, так как это индекс `arr.Length` (вне границ).

---

## 2. Диапазоны (..) — Срезы

Позволяет взять "кусок" массива. Результатом будет **новый** массив.

```csharp
int[] sub = numbers[1..4]; // Берем элементы с индекса 1 до 4 (не включая 4)
// Результат: { 20, 30, 40 }

int[] start = numbers[..3]; // С начала до 3 (0, 1, 2)
int[] end = numbers[3..];   // С 3 до конца (3, 4)
```

### Комбинируем с конца
```csharp
int[] middle = numbers[1..^1]; // Всё, кроме первого и последнего!
// { 20, 30, 40 }
```

---

## 3. Типы Index и Range

Под капотом это полноценные типы данных. Их можно хранить в переменных.

```csharp
Range myRange = 1..^1;
int[] result = numbers[myRange];
```

## 4. Практика: Обрезка данных

### Задание 6.3.1
У тебя есть массив названий файлов: 
`string[] files = { "image.png", "script.cs", "data.txt", "notes.md", "app.exe" };`
1. Используя диапазоны, создай новый массив, который содержит только "внутренние" файлы (без первого и последнего).
2. Используя индекс `^`, выведи название последнего файла.

---

## 5. Резюме
*   `^n` — отсчет с конца (начиная с 1).
*   `start..end` — диапазон (включая старт, исключая энд).
*   Идеально для обрезки списков.
