# 6.2. Многомерные и Зубчатые массивы

Иногда данных больше, чем в одной строке. Например, поле для "Крестиков-ноликов" или карта игрового уровня. В C# есть два способа хранить такие таблицы.

---

## 1. Прямоугольные массивы ([,] — Multidimensional)

Это "честная" таблица. Все строки одинаковой длины. В памяти это один цельный кусок.

```csharp
// [строки, столбцы]
int[,] matrix = new int[3, 3]; 

// Сразу с данными
int[,] field = {
    { 1, 2, 3 },
    { 4, 5, 6 },
    { 7, 8, 9 }
};

// Доступ:
Console.WriteLine(field[1, 1]); // 5 (центр)
```

---

## 2. Зубчатые массивы ([][] — Jagged)

Это "массив массивов". Каждая строка может иметь свою длину. Это более гибко и иногда быстрее для процессора.

```csharp
int[][] jagged = new int[3][];
jagged[0] = new int[2]; // первая строка - 2 элемента
jagged[1] = new int[5]; // вторая строка - 5 элементов
jagged[2] = new int[3]; // третья строка - 3 элемента

// Доступ (двойные скобки):
jagged[0][1] = 42;
```

### Сравнение:
*   **[,]** — Проще писать, меньше нагрузка на Garbage Collector (один объект в памяти).
*   **[][]** — Быстрее доступ (процессоры любят массивы массивов), позволяет экономить память, если строки разной длины.

---

## 3. Перебор (Вложенные циклы)

Для перебора таблицы нужен цикл внутри цикла.

```csharp
for (int i = 0; i < field.GetLength(0); i++) // по строкам
{
    for (int j = 0; j < field.GetLength(1); j++) // по столбцам
    {
        Console.Write(field[i, j] + " ");
    }
    Console.WriteLine();
}
```
*Заметь:* У `[,]` вместо `Length` используем `GetLength(0)` и `GetLength(1)`.

## 5. Резюме
*   `[,]` — фиксированная сетка.
*   `[][]` — гибкие строки.
*   Для обхода всегда нужны вложенные циклы.
