# 1.5. Консольный ввод/вывод

## Что ты узнаешь
- `Console.WriteLine` и `Console.Write` — вывод
- `Console.ReadLine` и `Console.ReadKey` — ввод
- Парсинг пользовательского ввода (Parse, TryParse, Convert)

---

## ЗАЧЕМ?
Прежде чем строить красивый UI в Uno Platform или Godot, нужно уметь общаться с программой через консоль. Это самый быстрый способ тестировать код и учиться.

## 1. Вывод — Console.Write и Console.WriteLine

```csharp
// WriteLine — выводит текст И переводит на новую строку
Console.WriteLine("Привет!");
Console.WriteLine("Мир!");
// Привет!
// Мир!

// Write — выводит текст БЕЗ перехода на новую строку
Console.Write("Привет, ");
Console.Write("Мир!");
// Привет, Мир!
```

### Интерполяция в выводе

```csharp
string name = "Алиса";
int hp = 100;

Console.WriteLine($"Имя: {name}, HP: {hp}");          // Имя: Алиса, HP: 100
Console.WriteLine($"Квадрат 5 = {5 * 5}");            // Квадрат 5 = 25
Console.WriteLine($"{"Текст",15}");                    // выравнивание вправо
Console.WriteLine($"{"Текст",-15}");                   // выравнивание влево
```

### Спецсимволы

```csharp
Console.WriteLine("Строка 1\nСтрока 2");  // \n — новая строка
Console.WriteLine("Табуляция:\tтекст");    // \t — табуляция
Console.WriteLine("Кавычки: \"текст\"");   // \" — кавычка внутри строки
Console.WriteLine("Обратный слеш: \\");    // \\ — обратный слеш
```

## 2. Ввод — Console.ReadLine

```csharp
Console.Write("Как тебя зовут? ");
string? name = Console.ReadLine();  // Ждёт пока пользователь введёт текст и нажмёт Enter
Console.WriteLine($"Привет, {name}!");
```

**Важно:** `ReadLine()` всегда возвращает `string?` (строку или null). Если нужно число — нужен парсинг!

## 3. Парсинг — превращаем строку в число

### Parse — простой, но опасный
```csharp
Console.Write("Введи возраст: ");
string? input = Console.ReadLine();
int age = int.Parse(input!);  // Если пользователь введёт "abc" — ИСКЛЮЧЕНИЕ!

Console.WriteLine($"Через 10 лет тебе будет {age + 10}");
```

### TryParse — безопасный (рекомендуется!)
```csharp
Console.Write("Введи число: ");
string? input = Console.ReadLine();

if (int.TryParse(input, out int number))
{
    Console.WriteLine($"Ты ввёл: {number}");
}
else
{
    Console.WriteLine("Это не число!");
}
```

### Convert — альтернативный способ
```csharp
string input = "42";
int number = Convert.ToInt32(input);      // 42
double pi = Convert.ToDouble("3.14");     // 3.14
bool flag = Convert.ToBoolean("true");    // true
```

**Рекомендация:** Для пользовательского ввода всегда используй `TryParse`. Для надёжных данных (из кода, конфигов) — `Parse` или `Convert`.

## 4. Console.ReadKey — одна клавиша

```csharp
Console.WriteLine("Нажми любую клавишу...");
ConsoleKeyInfo key = Console.ReadKey(intercept: true); // true = не показывать нажатие

Console.WriteLine($"\nТы нажал: {key.Key}");

if (key.Key == ConsoleKey.Escape)
    Console.WriteLine("Выход!");
```

## 5. Цвета в консоли

```csharp
Console.ForegroundColor = ConsoleColor.Green;
Console.WriteLine("Зелёный текст");

Console.ForegroundColor = ConsoleColor.Red;
Console.WriteLine("Красный текст");

Console.ResetColor(); // вернуть стандартный цвет
Console.WriteLine("Обычный текст");
```

## Частые ошибки

### 1. ReadLine возвращает string, а не число
```csharp
// ❌ Нельзя сложить строку и число напрямую
string input = Console.ReadLine()!;
// int result = input + 5;  // конкатенация "42" + 5 = "425"!

// ✅ Сначала парси:
int number = int.Parse(input);
int result = number + 5;  // 47
```

### 2. Не обработал невалидный ввод
```csharp
// ❌ Упадёт если ввести не число
int age = int.Parse(Console.ReadLine()!);

// ✅ Безопасно:
if (int.TryParse(Console.ReadLine(), out int age))
    Console.WriteLine($"Возраст: {age}");
else
    Console.WriteLine("Ошибка ввода!");
```

1. **⭐** Спроси имя и возраст, выведи: "Привет, {имя}! Через 10 лет тебе будет {возраст+10}".

3. **⭐** Используй `Console.ReadKey` — реагируй на стрелки (вверх/вниз/влево/вправо) разными сообщениями.
4. **⭐** Сделай "цветной" вывод: ошибки красным, предупреждения жёлтым, успех зелёным.
