# 3.5. Работа с null: Операторы чистоты

C# дает мощные инструменты для борьбы с ошибкой "Object reference not set to an instance of an object".

---

## 1. Null-conditional operator (?.) — "Элвис"

Позволяет безопасно обратиться к методу или свойству, даже если объект `null`.

**Было (Скучно):**
```csharp
string s = GetString();
int len = 0;
if (s != null)
{
    len = s.Length;
}
```

**Стало (Круто):**
```csharp
int? len = s?.Length; 
// Если s == null, то s?.Length вернет null.
// Программа не упадет!
```

---

## 2. Null-coalescing operator (??) — "Или запасной вариант"

Говорит: "Если слева null, возьми то, что справа".

```csharp
string name = null;
string displayName = name ?? "Аноним"; 
// displayName стало "Аноним", так как name был null.
```

Комбо с Элвисом:
```csharp
// "Попробуй взять длину, а если там null, верни 0"
int count = list?.Count ?? 0;
```

---

## 3. Null-coalescing assignment (??=)

"Присвой значение переменной, только если она сейчас пуста".
Полезно для ленивой инициализации (Lazy Initialization).

```csharp
List<int> numbers = null;

// ... код ...

numbers ??= new List<int>(); 
// Если numbers уже был создан — ничего не делать.
// Если был null — создать новый список.
numbers.Add(1);
```

## 4. Практика

### Задание 3.5.1
У тебя есть класс `User` с полем `Address`, внутри которого есть поле `City`.
`User user = null;`
Напиши **одну строку** кода, которая пытается достать `City`, а если `user` или `Address` равны null, возвращает "Unknown".

*(Ответ: `string city = user?.Address?.City ?? "Unknown";`)*
