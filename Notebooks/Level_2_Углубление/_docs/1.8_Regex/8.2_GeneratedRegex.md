# 8.2. GeneratedRegex: Производительность

В старом C# (и во многих других языках) регулярное выражение компилируется прямо во время работы программы. Это замедляет запуск и тратит память.

---

## 1. Source Generators (Генераторы кода)

В .NET 7+ появился атрибут `[GeneratedRegex]`. Он делает магию: читает твой шаблон **во время написания кода** и сразу генерирует быстрый C# код для этого поиска.

### Как это написать?
Тебе нужен `partial` класс и `partial` метод.

```csharp
using System.Text.RegularExpressions;

public partial class MyValidator
{
    // Компилятор сам напишет тело этого метода!
    [GeneratedRegex(@"^\d{4}$")]
    public static partial Regex OnlyFourDigits();
}

// Использование:
bool ok = MyValidator.OnlyFourDigits().IsMatch("1234");
```

---

## 2. Почему это лучше?
1. **Скорость:** Код уже готов, его не нужно "сочинять" при запуске.
2. **Память:** Не создаются лишние объекты в куче.
3. **Безопасность:** Если ты ошибся в шаблоне, ты узнаешь об этом сразу (IDE подсветит), а не когда программа упадет у пользователя.

## 3. Практика: Профессиональный валидатор

### Задание 8.2.1
Создай класс `PasswordChecker`. Используй `[GeneratedRegex]`, чтобы создать метод для проверки пароля:
* Должна быть хотя бы одна цифра.
* Должна быть хотя бы одна заглавная буква.
* Минимум 8 символов.

---

## 4. Резюме
Если ты пишешь современный проект на .NET 8/9 — забудь про `new Regex()`. Используй `[GeneratedRegex]`.
