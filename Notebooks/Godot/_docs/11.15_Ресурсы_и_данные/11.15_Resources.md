# 11.5. Кастомные Ресурсы (Data-Driven Design)

В Godot есть магический класс `Resource`. В C# это позволяет нам создавать собственные базы данных прямо внутри редактора.

---

## 1. Зачем это нужно?
Представь, что в твоей игре 100 видов мечей. Хранить их характеристики в коде игрока — ужасно (нарушение SRP). 
Лучше создать один C#-класс "Тип оружия" и насоздавать из него файлов-данных.

---

## 2. Создание ресурса на C#

```csharp
using Godot;

[GlobalClass] // Позволяет создавать этот ресурс через кнопку "New Resource"
public partial class WeaponData : Resource
{
    [Export] public string Name;
    [Export] public int Damage;
    [Export] public Texture2D Icon;
}
```

---

## 3. Использование в Игроке

```csharp
public partial class Player : Node
{
    [Export] public WeaponData CurrentWeapon;

    public void Attack()
    {
        GD.Print($"Атака мечом {CurrentWeapon.Name} на {CurrentWeapon.Damage} урона!");
    }
}
```

---

## 4. Почему это круто для C#?
1. **Строгая типизация**: Ты никогда не перепутаешь Меч и Зелье, потому что компилятор C# проверит типы ресурсов.
2. **Сериализация**: Godot сам умеет сохранять и загружать эти C#-классы в файлы `.tres`.

---

## 5. Практика: База монстров
1. Создай класс `MonsterData` (HP, Speed, Name).
2. Создай в редакторе три файла ресурсов: "Goblin.tres", "Orc.tres", "Dragon.tres".
3. Напиши скрипт `Spawner`, который случайно выбирает один из этих ресурсов и выводит его данные в консоль.
*Здесь ты практикуешь: Классы, аттрибуты [Export] и работу с объектами.*

---

## 6. Резюме
*   `Resource` — это C# класс для хранения данных.
*   `[GlobalClass]` — делает твой класс доступным во всем движке.
*   Это лучший способ реализовать инвентарь или список навыков.
