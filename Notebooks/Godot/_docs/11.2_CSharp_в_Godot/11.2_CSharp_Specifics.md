# 11.2. C# в Godot: Специфика

C# в Godot — это полноценный .NET, но с парой важных дополнений, которые связывают код с редактором.

---

## 1. Атрибут [Export]

Это твоё окно из кода в редактор. Если ты пометишь переменную этим атрибутом, ты сможешь менять её прямо в Godot, не заходя в скрипт.

```csharp
[Export]
public float Speed = 200.0f; // Теперь в инспекторе Godot появится поле Speed

[Export]
public string PlayerName = "Hero";
```
**Зачем?** Чтобы геймдизайнер (или ты сам) мог быстро настроить скорость прыжка или цвет врага, просто двигая ползунки в редакторе.

---

## 2. Доступ к другим узлам (GetNode)

Если твой скрипт висит на Игроке, и ты хочешь изменить текст в Label, тебе нужно его найти.

```csharp
// Ищем узел по имени (иерархия)
Label myLabel = GetNode<Label>("UI/ScoreLabel");
myLabel.Text = "Score: 100";
```
*Совет:* Не вызывай `GetNode` в `_Process` (это медленно). Вызывай его один раз в `_Ready` и сохраняй ссылку в переменную.

---

## 3. partial классы
Ты заметил, что все классы в Godot имеют пометку `partial`. 
Это нужно, потому что Godot сам генерирует часть кода за кулисами (чтобы связать твой C# с внутренностями движка). Без `partial` ничего не заработает.

---

## 4. Практика: Настраиваемый герой

### Задание 11.2.1
1. Создай узел `CharacterBody2D`. Внутри него создай `Sprite2D` и `Label`.
2. Создай скрипт.
3. Добавь `[Export] public string Title`.
4. В `_Ready` найди `Label` и запиши в него текст из переменной `Title`.
5. Поменяй текст в редакторе Godot и запусти игру.

---

## 5. Резюме
*   `[Export]` — выносит настройки в редактор.
*   `GetNode<T>("путь")` — находит другие объекты в сцене.
*   `Vector2` — главный тип для позиций и скоростей.
