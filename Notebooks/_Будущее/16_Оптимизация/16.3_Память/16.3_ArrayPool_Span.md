# 16.2. Оптимизация памяти: Span, Memory и stackalloc

Современный C# (начиная с 7.2+) позволяет работать с памятью почти так же эффективно, как C++, но при этом оставаться в безопасности под присмотром Garbage Collector. Главные инструменты здесь — `Span<T>` и `Memory<T>`.

---

## 1. Span<T>: "Окно" в память

`Span<T>` — это структура, которая позволяет смотреть на непрерывный кусок памяти (массив, строку или нативный буфер) без его копирования.

### Проблема копирования
```csharp
string text = "Hello, World";
string sub = text.Substring(0, 5); // ❌ Создает новую строку в куче (аллокация!)
```

### Решение через Span
```csharp
ReadOnlySpan<char> span = text.AsSpan();
ReadOnlySpan<char> subSpan = span.Slice(0, 5); // ✅ Это просто "окно". Ноль аллокаций!
```

**Ограничение:** `Span<T>` — это `ref struct`. Его нельзя хранить в полях классов, нельзя использовать в `async` методах (он живет только на стеке).

---

## 2. stackalloc: Память без кучи

С помощью `stackalloc` можно выделить массив прямо на стеке. Он удалится мгновенно при выходе из метода, не нагружая Garbage Collector.

```csharp
// Выделяем 100 байт на стеке
Span<byte> buffer = stackalloc byte[100]; 

// Идеально для небольших временных буферов
int bytesRead = stream.Read(buffer);
```
*Внимание:* Стек ограничен (обычно 1 МБ). Не выделяй там огромные массивы, иначе получишь `StackOverflowException`.

---

## 3. Memory<T>: Span для async

Если тебе нужно хранить срез памяти в классе или передавать его в `async/await`, используй `Memory<T>`.

```csharp
public async Task ProcessDataAsync(Memory<byte> data)
{
    // Memory можно передавать через await
    await Task.Delay(100);
    
    // Но для работы его нужно превратить в Span
    Span<byte> span = data.Span;
    span[0] = 42;
}
```

---

## 4. ArrayPool<T>: Аренда массивов

Вместо `new byte[4096]` (что заставляет GC работать при удалении), можно "арендовать" массив у системы и вернуть его, когда он не нужен.

```csharp
using System.Buffers;

// Арендуем массив
byte[] buffer = ArrayPool<byte>.Shared.Rent(4096);

try 
{
    // Работаем с ним...
}
finally 
{
    // Возвращаем в пул (обязательно!)
    ArrayPool<byte>.Shared.Return(buffer);
}
```

## 5. Практика: Быстрый парсер чисел

### Задание 16.2.1
Напиши метод `int ParseSum(string input)`, который принимает строку вида `"123,456,789"` и возвращает сумму чисел.
1.  **Запрещено** использовать `string.Split()`.
2.  Используй `AsSpan()` и `Slice()`, чтобы находить куски строки между запятыми.
3.  Используй `int.Parse(span)` для превращения среза в число.
4.  Замерь скорость через BenchmarkDotNet по сравнению с обычным `Split().Select(int.Parse).Sum()`.

---

## 6. Резюме
*   `Span<T>` — быстрый доступ к любой памяти без аллокаций (только стек).
*   `Memory<T>` — для полей классов и асинхронности.
*   `stackalloc` — массивы на стеке.
*   `ArrayPool` — переиспользование массивов в куче.
