# 20.1. Итоговый проект Uno: Чистая Архитектура

Не пиши всё в одном проекте. Разделяй.

---

## 1. Слои
1.  **Core (Domain)**: Только классы данных (`User`, `Order`). Никаких библиотек.
2.  **Application**: Логика (`LoginUser`, `CreateOrder`). Интерфейсы (`IRepository`).
3.  **Infrastructure**: Реализация интерфейсов (`SqliteRepository`, `FileLogger`).
4.  **Presentation (UI)**: Uno Platform (XAML, ViewModels).

Это позволяет менять UI (Uno -> MAUI) или Базу (SQLite -> PostgreSQL), не переписывая логику.
