# 1.3. HashSet: Только уникальные

`HashSet<T>` — это как `Dictionary`, у которого есть только ключи, но нет значений. Главная фишка: в нем **не может быть дубликатов**.

---

## 1. Зачем это нужно?

1. **Уникальность:** Если ты добавишь "Apple" 10 раз, внутри останется только одна "Apple".
2. **Скорость:** Проверка "есть ли это в списке" (метод `Contains`) работает так же мгновенно (O(1)), как поиск в словаре. В `List` это бы заняло кучу времени.

---

## 2. Операции множеств

Это чистая математика, очень полезная в логике игр.

```csharp
var setA = new HashSet<int> { 1, 2, 3 };
var setB = new HashSet<int> { 3, 4, 5 };

// Пересечение (только общие)
setA.IntersectWith(setB); // Останется только { 3 }

// Объединение (все вместе без дублей)
setA.UnionWith(setB); // Будет { 1, 2, 3, 4, 5 }
```

## 4. Резюме
*   Нужна уникальность? -> `HashSet`.
*   Нужна скорость проверки наличия? -> `HashSet`.
*   Порядок элементов в `HashSet` **не гарантируется**.
