# 1.2. Dictionary: Поиск за мгновение

Если в `List` ты ищешь по номеру (индексу), то в `Dictionary` ты ищешь по **Ключу**. Ключом может быть что угодно: строка, число или даже твой класс.

---

## 1. Как это устроено? (Хэш-таблица)

Словарь не перебирает все элементы подряд. Он берет твой Ключ, прогоняет его через функцию (GetHashCode) и сразу получает адрес в памяти, где лежит Значение.
**Скорость поиска:** O(1) — мгновенно, независимо от того, 10 элементов в словаре или 10 миллионов.

---

## 2. Использование

```csharp
var scores = new Dictionary<string, int>();

// Добавление
scores.Add("Alex", 100);
scores["Bob"] = 80; // Более удобный способ

// Чтение (Опасно!)
int s = scores["Alex"]; // Если ключа нет - программа упадет!

// Чтение (Безопасно)
if (scores.TryGetValue("Clara", out int val))
{
    Console.WriteLine(val);
}
```

---

## 3. Особенности ключей
1. Ключ должен быть **уникальным**. (Нельзя добавить двух "Alex").
2. Ключ должен быть **неизменяемым** (Immutable). Если ты изменишь объект, который является ключом, ты его больше никогда не найдешь.

---

## 4. Практика: База игроков

### Задание 1.2.1
Создай словарь `Dictionary<int, string> players`.
1. Ключ — ID игрока, Значение — его имя.
2. Добавь 3 игроков.
3. Напиши метод, который по введенному ID выводит имя или фразу "Игрок не найден".

---

## 5. Резюме
*   Словарь — самая быстрая коллекция для поиска по ключу.
*   `TryGetValue` — твой лучший друг.
*   Ключ — уникален и неизменен.
