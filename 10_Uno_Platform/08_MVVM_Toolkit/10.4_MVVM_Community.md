# 10.4. MVVM и Community Toolkit

Писать `INotifyPropertyChanged` вручную для каждого поля — долго и скучно. Поэтому Microsoft создала библиотеку **Community Toolkit**, которая делает это за тебя.

---

## 1. Что такое MVVM?
Это архитектура для UI:
*   **Model**: Данные (например, из базы).
*   **View**: Твой XAML файл.
*   **ViewModel**: Посредник. Он готовит данные для View и обрабатывает команды от кнопок.

---

## 2. Магия Атрибутов

С использованием тулкита твой код сокращается в 5 раз:

```csharp
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;

// partial класс обязателен для работы генератора кода
public partial class MainViewModel : ObservableObject
{
    [ObservableProperty]
    private string _userName; // Генератор сам создаст свойство UserName с уведомлением!

    [RelayCommand]
    private void Save()
    {
        // Логика сохранения
    }
}
```

### В XAML:
```xml
<TextBox Text="{Binding UserName, Mode=TwoWay}" />
<Button Content="Сохранить" Command="{Binding SaveCommand}" />
```

---

## 3. Зачем это нужно?
1. **Тестируемость**: Ты можешь протестировать логику ViewModel без запуска приложения.
2. **Чистота**: В твоем `MainPage.xaml.cs` (code-behind) будет пусто. Вся логика — в отдельном чистом классе.

---

## 4. Практика: Автоматизация

### Задание 10.4.1
1. Подключи NuGet пакет `CommunityToolkit.Mvvm`.
2. Создай `MainViewModel`.
3. Сделай свойство `Age` с атрибутом `[ObservableProperty]`.
4. Сделай команду `IncrementAgeCommand` через `[RelayCommand]`.
5. Привяжи всё в XAML.

---

## 5. Резюме
*   `ObservableObject` — базовый класс для ViewModel.
*   `[ObservableProperty]` — создаёт умное свойство из приватного поля.
*   `[RelayCommand]` — создаёт команду для кнопки из обычного метода.
