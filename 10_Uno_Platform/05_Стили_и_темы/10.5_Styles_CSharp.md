# 10.5. Стили и Темы: Управление из C#

В UI-разработке стиль — это не только дизайн, это способ **переиспользования** настроек. В C# мы создаем методы, а в XAML мы создаем Стили.

---

## 1. Ресурсы (XAML + C#)
Любой объект (цвет, шрифт, даже целый класс) можно положить в `ResourceDictionary` и вызывать его по ключу.

```xml
<Page.Resources>
    <SolidColorBrush x:Key="BrandColor" Color="Blue" />
    <Style x:Key="MyButtonStyle" TargetType="Button">
        <Setter Property="Background" Value="{StaticResource BrandColor}" />
        <Setter Property="FontSize" Value="24" />
    </Style>
</Page.Resources>

<Button Style="{StaticResource MyButtonStyle}" Content="Жми!" />
```

---

## 2. Доступ к стилям из C#
Иногда нужно сменить стиль кнопки программно.

```csharp
// Ищем стиль в ресурсах по ключу
if (Resources.TryGetValue("MyButtonStyle", out object style))
{
    myButton.Style = (Style)style;
}
```

---

## 3. Динамическая смена темы (C# Logic)
Uno позволяет менять тему приложения (Light/Dark) одной строчкой кода.

```csharp
// Переключаем тему
if (App.Current.RequestedTheme == ApplicationTheme.Dark)
    App.Current.RequestedTheme = ApplicationTheme.Light;
```

---

## 4. Практика: Цветовая схема
1. Создай во ViewModel свойство `CurrentColor` (string).
2. Привяжи его к фону `Grid`.
3. Напиши метод в C#, который меняет этот цвет в зависимости от времени суток. 
*Здесь ты практикуешь: логику `if/else`, свойства и привязку данных (Binding).*

---

## 5. Резюме
*   Стили в XAML — это как классы в CSS или C#.
*   C# может менять стили "на лету", реагируя на действия пользователя.
*   Использование ресурсов избавляет от магических чисел (цветов и размеров) в коде.
