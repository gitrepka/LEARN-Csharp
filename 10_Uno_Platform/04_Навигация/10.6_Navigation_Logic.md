# 10.6. Навигация и Управление памятью

Когда ты переходишь с одной страницы на другую, старая страница может остаться в памяти Кучи (Heap). Если на ней висят активные таймеры или подписки на события, программа начнет тормозить.

---

## 1. Навигация через Frame (C#)
В Uno навигация управляется классом `Frame`.

```csharp
// Переход на страницу настроек с передачей данных (ID пользователя)
Frame.Navigate(typeof(SettingsPage), 123);
```

---

## 2. Получение параметров (OnNavigatedTo)
C# метод, который срабатывает при открытии страницы.

```csharp
protected override void OnNavigatedTo(NavigationEventArgs e)
{
    base.OnNavigatedTo(e);
    // Извлекаем переданный параметр (наш ID)
    int userId = (int)e.Parameter;
}
```

---

## 3. Очистка памяти (IDisposable и OnNavigatedFrom)
Если твоя ViewModel подписана на глобальные события, её нужно "прибирать" за собой.

```csharp
public partial class MainViewModel : IDisposable
{
    public void Dispose()
    {
        // Отписываемся от событий, останавливаем таймеры
        GlobalEvents.OnMessage -= HandleMessage;
    }
}
```

---

## 4. Практика: Двухстраничное приложение
1. Создай `MainPage` и `DetailsPage`.
2. На первой странице — `ListView` со списком имен (C# List).
3. При клике на имя — переходи на вторую страницу и передавай выбранное имя.
4. На второй странице выведи это имя.
*Здесь ты практикуешь: Навигацию, кастинг типов (object -> string) и работу со списками.*

---

## 5. Резюме
*   Навигация — это передача объектов между классами страниц.
*   Всегда думай, когда объект уничтожается (GC), чтобы не копить мусор в памяти.
*   `OnNavigatedTo` — аналог конструктора для UI-логики.
