# 10.3. Data Binding: Живая связь данных и UI

Data Binding (привязка данных) — это механизм, который позволяет свойствам UI-элементов (например, текст в `TextBlock`) автоматически "следить" за значениями в твоем коде.

---

## 1. Зачем это нужно?
Без привязки тебе пришлось бы каждый раз писать: `myLabel.Text = currentScore.ToString();`. 
С привязкой ты один раз говоришь: "Этот текст всегда равен переменной Score", и Uno сам обновляет экран.

---

## 2. DataContext
Чтобы привязка заработала, элементу нужно указать "Источник данных" — объект, в котором лежат нужные переменные. Это делается через свойство `DataContext`.

```csharp
// В MainPage.xaml.cs
public MainPage()
{
    this.InitializeComponent();
    this.DataContext = new UserProfile { Name = "Aibek" };
}
```

---

## 3. Синтаксис {Binding}
В XAML мы указываем, к какому свойству объекта привязаться.

```xml
<TextBlock Text="{Binding Name}" />
```

---

## 4. Как уведомлять UI? (INotifyPropertyChanged)
Если ты просто изменишь `Name = "Ivan"`, экран **не обновится**. Почему? Потому что C# не сообщает UI-потоку об изменениях.
Чтобы это работало, твой класс должен реализовать интерфейс-уведомитель.

```csharp
public class UserProfile : INotifyPropertyChanged
{
    private string _name;
    public string Name 
    {
        get => _name;
        set 
        {
            _name = value;
            // Кричим UI: "Эй, свойство Name изменилось!"
            OnPropertyChanged(nameof(Name));
        }
    }

    public event PropertyChangedEventHandler PropertyChanged;
    protected void OnPropertyChanged(string name) => 
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(name));
}
```

## 6. Резюме
*   `DataContext` — откуда берем данные.
*   `{Binding}` — к чему привязываемся.
*   `INotifyPropertyChanged` — обязательный контракт для обновления экрана.
