# 13.3. JSON API: Реальные данные

В 99% случаев ты будешь общаться с API, которые отдают данные в формате JSON.

---

## 1. Пример API
Допустим, есть сайт `api.weather.com`, который на запрос GET отдает:
```json
{
  "temp": 25,
  "city": "Moscow"
}
```

## 2. Создаем класс-модель
```csharp
public class WeatherData
{
    [JsonPropertyName("temp")]
    public int Temperature { get; set; }
    
    [JsonPropertyName("city")]
    public string City { get; set; }
}
```

---

## 3. Получаем и превращаем (GetFromJsonAsync)
`HttpClient` умеет сам делать десериализацию.

```csharp
var weather = await client.GetFromJsonAsync<WeatherData>("https://api.weather.com/...");
Console.WriteLine($"В городе {weather.City} сейчас {weather.Temperature} градусов.");
```

---

## 4. Практика: Курс валют
Найди в интернете открытый API курсов валют (например, CoinGecko или ЦБ РФ).
Напиши программу, которая выводит текущий курс Биткоина к Доллару.

---

## 5. Резюме
*   API — это сайт для роботов.
*   `GetFromJsonAsync<T>` — самый быстрый способ получить объект из интернета.
