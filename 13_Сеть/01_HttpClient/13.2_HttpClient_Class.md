# 13.2. HttpClient: Делаем запросы

В .NET есть мощный класс для работы с сетью — `HttpClient`.

---

## 1. Правило жизни
**HttpClient должен быть один на всё приложение.**
Не создавай его в `using` каждый раз! Это исчерпает свободные порты твоего компьютера.
Создай `static readonly HttpClient client = new HttpClient();` один раз.

---

## 2. GET-запрос (Скачивание)

```csharp
string url = "https://example.com";
string html = await client.GetStringAsync(url);
Console.WriteLine(html);
```

---

## 3. POST-запрос (Отправка)

```csharp
var data = new StringContent("Hello", Encoding.UTF8, "text/plain");
var response = await client.PostAsync("https://example.com/api", data);

if (response.IsSuccessStatusCode)
{
    Console.WriteLine("Отправлено!");
}
```

---

## 4. Практика: Качалка
Напиши метод `DownloadPage(string url)`, который скачивает HTML-код страницы и сохраняет его в файл на диске.

---

## 5. Резюме
*   `HttpClient` — один на всех.
*   Все методы сетевые — **асинхронные** (`await`).
*   Всегда проверяй `IsSuccessStatusCode`.
