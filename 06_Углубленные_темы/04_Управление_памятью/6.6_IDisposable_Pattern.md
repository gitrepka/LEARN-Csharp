# 6.6. Паттерн IDisposable

GC умеет чистить только **память**. Но он ничего не знает про "Внешние ресурсы":
*   Открытые файлы на диске.
*   Соединения с базой данных.
*   Камеры или микрофоны.

Если ты просто перестанешь ссылаться на класс `FileStream`, GC удалит объект из памяти, но файл в Windows может остаться "заблокированным".

---

## 1. Интерфейс IDisposable
Этот интерфейс говорит: "У меня есть то, что нужно закрыть вручную".

```csharp
public class Camera : IDisposable
{
    public void Dispose()
    {
        // Код для выключения камеры
    }
}
```

---

## 2. Оператор using (Твой лучший друг)
Вместо того чтобы вызывать `.Dispose()` руками, используй `using`. Он гарантирует вызов метода, даже если программа упадет.

```csharp
using (var cam = new Camera())
{
    // Работаем...
} // Метод Dispose вызовется здесь автоматически
```

---

## 3. Резюме
Если в классе есть метод `Dispose`, ты **обязан** использовать его внутри `using`.
