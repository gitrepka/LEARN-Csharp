# 6.4. Рефлексия (Reflection): Код под микроскопом

Рефлексия позволяет программе изучать саму себя и менять свое поведение "на лету".

---

## 1. Зачем это нужно?
*   Написать сериализатор (как JSON), который сам найдет все свойства класса.
*   Написать плагинную систему (загружать `.dll` из папки и искать в них нужные методы).
*   Достать данные из `private` полей (не делай этого в обычном коде, только для тестов или хаков!).

---

## 2. Как это работает?

```csharp
var player = new Player();
Type type = player.GetType(); // Получаем метаданные объекта

// Смотрим все методы класса
var methods = type.GetMethods();
foreach (var m in methods)
{
    Console.WriteLine($"Найден метод: {m.Name}");
}

// Вызываем метод по имени
var myMethod = type.GetMethod("Heal");
myMethod.Invoke(player, new object[] { 10 });
```

---

## 3. Резюме
Рефлексия — мощный, но медленный инструмент. Используй её только там, где без неё нельзя (архитектурные задачи).
