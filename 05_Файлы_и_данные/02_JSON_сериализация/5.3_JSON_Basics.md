# 5.3. JSON Сериализация: Сохраняем объекты

Просто писать текст в файл — это хорошо, но как сохранить сложный объект (например, Игрока с инвентарем и координатами)? 
Для этого существует **Сериализация** — превращение объекта в строку.

---

## 1. Что такое JSON?
Это стандарт текста, который понимают все языки программирования. 
Объект `Player` в JSON выглядит так:
```json
{
  "Name": "Alex",
  "Health": 100
}
```

---

## 2. System.Text.Json

В C# есть встроенная мощная библиотека для работы с JSON.

```csharp
using System.Text.Json;

var player = new Player { Name = "Alex", Health = 100 };

// 1. ПРЕВРАЩАЕМ В ТЕКСТ (Сериализация)
string json = JsonSerializer.Serialize(player);
File.WriteAllText("save.json", json);

// 2. ВОССТАНАВЛИВАЕМ (Десериализация)
string savedJson = File.ReadAllText("save.json");
Player restoredPlayer = JsonSerializer.Deserialize<Player>(savedJson);
```

---

## 3. Настройка (JsonSerializerOptions)
По умолчанию JSON получается "сжатым" в одну строку. Чтобы его мог прочитать человек, добавь настройки:

```csharp
var options = new JsonSerializerOptions { WriteIndented = true };
string prettyJson = JsonSerializer.Serialize(player, options);
```

---

## 4. Атрибуты
Ты можешь управлять тем, как поля попадают в JSON.
*   `[JsonPropertyName("player_name")]` — изменить имя поля в файле.
*   `[JsonIgnore]` — вообще не сохранять это поле (например, временный пароль).

---

## 6. Резюме
*   Сериализация — объект -> строка.
*   Десериализация — строка -> объект.
*   JSON — стандарт для сохранений и интернета.
