# 5.2. Потоки (Streams) и StreamReader

`File.ReadAllText` хорош для маленьких заметок. Но если ты попытаешься так прочитать файл в 2 ГБ, твоя программа "съест" всю оперативную память и упадет. 
Для больших данных (и для скорости) используются **Потоки**.

---

## 1. Что такое поток (Stream)?
Представь файл как бочку с водой. 
`ReadAllText` — это попытка выпить всю бочку залпом.
`Stream` — это тонкая трубка, по которой ты пьешь воду маленькими глотками (буферами).

---

## 2. Запись через StreamWriter

```csharp
using System.IO;

string path = "large_data.txt";

// Блок using ГАРАНТИРУЕТ, что файл закроется, даже если произойдет ошибка
using (StreamWriter writer = new StreamWriter(path))
{
    for (int i = 0; i < 1000; i++)
    {
        writer.WriteLine($"Строка номер {i}");
    }
} // Здесь writer.Dispose() вызывается автоматически
```

---

## 3. Чтение через StreamReader

```csharp
using (StreamReader reader = new StreamReader(path))
{
    string line;
    // Читаем файл построчно, пока он не кончится
    while ((line = reader.ReadLine()) != null)
    {
        Console.WriteLine(line);
    }
}
```

---

## 4. Почему `using` обязателен?
Когда ты открываешь файл, операционная система "блокирует" его. Если ты забудешь его закрыть (`.Close()`), другие программы не смогут его открыть, а твой компьютер может начать тормозить из-за утечки ресурсов. `using` делает это за тебя автоматически.

---

## 6. Резюме
*   `StreamWriter` / `StreamReader` — для эффективной работы с текстом.
*   `using` — всегда используй для потоков.
*   Потоки позволяют работать с файлами любого размера.
