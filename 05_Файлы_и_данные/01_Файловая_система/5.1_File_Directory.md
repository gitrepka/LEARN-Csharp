# 5.1. Файловая система: File и Directory

До этого момента все наши данные жили только в оперативной памяти и исчезали после закрытия программы. Пора научиться сохранять их на диск.

---

## 1. Класс File: Работа с файлами
Это статический класс для простых операций "в одну строку".

```csharp
using System.IO;

string path = "test.txt";

// 1. Запись
File.WriteAllText(path, "Привет, мир!");

// 2. Проверка существования
if (File.Exists(path))
{
    // 3. Чтение
    string content = File.ReadAllText(path);
    Console.WriteLine(content);
}

// 4. Удаление
// File.Delete(path);
```

---

## 2. Класс Directory: Работа с папками

```csharp
string folder = "MyData";

if (!Directory.Exists(folder))
{
    Directory.CreateDirectory(folder);
}

// Получить список всех файлов в папке
string[] files = Directory.GetFiles(folder);
```

---

## 3. Класс Path: Правильные пути
**Никогда** не пиши пути вот так: `folder + "\\" + file`. В Windows это сработает, а в Linux или на Android — нет. Используй `Path`.

```csharp
string fullPath = Path.Combine("MyProject", "Data", "save.txt");
// Он сам подставит нужный слеш (/ или \) в зависимости от системы.

string extension = Path.GetExtension(fullPath); // ".txt"
string fileName = Path.GetFileName(fullPath);   // "save.txt"
```

## 4. Практика: Логгер

### Задание 5.1.1
Напиши метод `Log(string message)`.
1. Он должен проверять, существует ли папка `Logs`. Если нет — создавать её.
2. Он должен записывать сообщение в файл `Logs/log.txt`.
3. Используй `File.AppendAllText`, чтобы новые сообщения добавлялись в конец файла, а не затирали старые.
4. Добавь к сообщению текущую дату и время.

## 5. Резюме
*   `File` — для быстрых действий с файлами.
*   `Directory` — для управления папками.
*   `Path` — для безопасной сборки путей.
