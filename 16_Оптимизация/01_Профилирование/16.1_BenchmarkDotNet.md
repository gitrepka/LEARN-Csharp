# 16.1. BenchmarkDotNet: Научный подход к скорости

Ты написал два метода и споришь с другом, какой быстрее. Как проверить?
Замерять через `DateTime.Now` или `Stopwatch` — ненадежно. На результат влияет всё: фоновые процессы Windows, "прогрев" процессора, работа Garbage Collector.

---

## 1. BenchmarkDotNet
Это стандартная библиотека для замеров. Она запускает твой код тысячи раз, считает статистику, отклонения и выделенную память.

### Установка
`dotnet add package BenchmarkDotNet`

---

## 2. Как написать тест

```csharp
using BenchmarkDotNet.Attributes;
using BenchmarkDotNet.Running;

[MemoryDiagnoser] // Покажет, сколько памяти выделено
public class StringVsBuilder
{
    [Benchmark]
    public string StringConcat()
    {
        string s = "";
        for (int i = 0; i < 100; i++) s += i;
        return s;
    }

    [Benchmark]
    public string StringBuilder()
    {
        var sb = new System.Text.StringBuilder();
        for (int i = 0; i < 100; i++) sb.Append(i);
        return sb.ToString();
    }
}

// Запуск
// BenchmarkRunner.Run<StringVsBuilder>();
```
