# 16.1. BenchmarkDotNet: Профессиональный замер производительности

Оптимизация без замеров — это гадание на кофейной гуще. BenchmarkDotNet (BDN) превращает замеры в научный процесс, исключая влияние JIT-прогрева, фоновых задач и Garbage Collector.

---

## 1. Как правильно настроить тест

Для точных результатов всегда запускай бенчмарки в **Release** конфигурации и **вне отладчика**.

```csharp
using BenchmarkDotNet.Attributes;
using BenchmarkDotNet.Order;

[MemoryDiagnoser]       // Анализ аллокаций памяти
[Orderer(SummaryOrderPolicy.FastestToSlowest)] // Сортировка результатов
[RankColumn]            // Рейтинг (1, 2, 3...)
public class CollectionsBenchmark
{
    private List<int> _list;
    private int[] _array;

    [Params(100, 1000, 10000)] // Тестирование на разных объемах данных
    public int N;

    [GlobalSetup]
    public void Setup()
    {
        _list = Enumerable.Range(0, N).ToList();
        _array = Enumerable.Range(0, N).ToArray();
    }

    [Benchmark(Baseline = true)] // Эталон для сравнения
    public int SumList()
    {
        int sum = 0;
        foreach (var i in _list) sum += i;
        return sum;
    }

    [Benchmark]
    public int SumArray()
    {
        int sum = 0;
        foreach (var i in _array) sum += i;
        return sum;
    }
}
```

## 2. Чтение результатов (Разбор колонок)

После запуска ты увидишь таблицу. Что значат эти цифры?

*   **Mean**: Среднее время выполнения одного вызова.
*   **Error / StdDev**: Насколько сильно результаты "гуляют". Если они большие (> 5%) — замер ненадежный (возможно, мешал браузер или антивирус).
*   **Ratio**: Во сколько раз этот метод медленнее/быстрее, чем `Baseline`.
*   **Allocated**: Сколько памяти в куче (Heap) было выделено. **Цель: 0 B.** Если там есть цифры, значит GC будет тормозить твою игру или сервер.

## 3. Продвинутые фишки

### Hardware Intrinsics (SIMD)
BDN может показать, использует ли твой код инструкции процессора (AVX2, SSE).
```csharp
[DisassemblyDiagnoser(printSource: true)] // Показать ассемблерный код
public class SimdBenchmark { ... }
```

### Тестирование разных версий .NET
Ты можешь сравнить, как один и тот же код работает на .NET 8 и .NET 10.
```csharp
[SimpleJob(RuntimeMoniker.Net80)]
[SimpleJob(RuntimeMoniker.Net100)]
public class VersionComparison { ... }
```

## 5. Резюме
*   Бенчмарки запускаются только в **Release**.
*   **Allocated = 0 B** — золотой стандарт оптимизации.
