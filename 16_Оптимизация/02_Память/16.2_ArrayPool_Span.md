# 16.2. ArrayPool и Span: Экономим память

В играх и серверах главная проблема — **Garbage Collector (GC)**. Когда он просыпается, чтобы собрать мусор, программа замирает (фриз).
Решение: не создавать мусор.

---

## 1. Проблема: Временные массивы
Если тебе нужен массив всего на секунду (буфер для чтения файла), а потом ты его выбрасываешь — это нагрузка на GC.

---

## 2. Решение: Аренда массивов (ArrayPool)
Мы не покупаем массив, мы берем его в аренду у системы.

```csharp
using System.Buffers;

// Дай мне массив МИНИМУМ на 100 элементов
int[] buffer = ArrayPool<int>.Shared.Rent(100);

try
{
    // Работаем с buffer...
    // Важно: размер массива может быть больше 100 (например 128)
}
finally
{
    // ОБЯЗАТЕЛЬНО возвращаем обратно!
    ArrayPool<int>.Shared.Return(buffer);
}
```

---

## 3. Резюме
*   `ArrayPool` — это "библиотека" массивов. Взял -> Попользовался -> Вернул.
*   Это позволяет вообще не выделять новую память в цикле работы программы.
