# 18.1. Minimal API: Сервер за минуту

Раньше для API нужно было создавать кучу классов. Сейчас (в .NET 6+) это выглядит так:

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

// Маршрут GET /hello
app.MapGet("/hello", () => "Hello World!");

// Маршрут POST /users (принимает объект)
app.MapPost("/users", (User user) => 
{
    Console.WriteLine($"Создан юзер: {user.Name}");
    return Results.Ok(user);
});

app.Run();
```

Это полноценный веб-сервер. Ты можешь открыть браузер, ввести `localhost:5000/hello` и увидеть ответ.
