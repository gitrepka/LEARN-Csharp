# 18.2. SignalR: Мгновенная связь

HTTP — это "Спросил -> Получил ответ".
SignalR — это "Постоянная труба". Сервер может сам отправить сообщение клиенту в любой момент.

---

## 1. Хаб (Hub)
Это центр общения.

```csharp
public class ChatHub : Hub
{
    public async Task SendMessage(string user, string message)
    {
        // Рассылаем всем подключенным клиентам
        await Clients.All.SendAsync("ReceiveMessage", user, message);
    }
}
```

---

## 2. Подключение (в Program.cs)
```csharp
builder.Services.AddSignalR();
// ...
app.MapHub<ChatHub>("/chat");
```

Теперь любой JS, C# или Godot клиент может подключиться к `/chat` и общаться в реальном времени.
