# 8.4. Поведенческие паттерны (Behavioral Patterns)

## Введение
Поведенческие паттерны заботятся об алгоритмах и взаимодействии между объектами.

---

## 1. Strategy (Стратегия)
**Суть:** Определяет семейство алгоритмов, инкапсулирует их и делает их взаимозаменяемыми.
**Где использовать:** Разные типы передвижения AI (патруль, погоня, побег), разные способы оплаты или типы урона.

```csharp
public interface IMoveStrategy { void Move(); }
public class WalkStrategy : IMoveStrategy { public void Move() => Console.WriteLine("Walking..."); }
public class FlyStrategy : IMoveStrategy { public void Move() => Console.WriteLine("Flying!"); }

public class Enemy
{
    private IMoveStrategy _strategy;
    public void SetStrategy(IMoveStrategy s) => _strategy = s;
    public void ExecuteMove() => _strategy.Move();
}
```

---

## 2. Observer (Наблюдатель / Издатель-Подписчик)
**Суть:** Создает механизм, позволяющий объекту уведомлять другие объекты об изменениях своего состояния.
**Где использовать:** `EventBus`, интерфейс (клик по кнопке), система достижений (ждем смерти врага).

```csharp
public class Boss
{
    public event Action OnBossDefeated; // В C# события — это встроенный Observer

    public void Die()
    {
        Console.WriteLine("Boss is down!");
        OnBossDefeated?.Invoke();
    }
}

// Подписчики:
boss.OnBossDefeated += () => Console.WriteLine("UI: Show Victory Screen");
boss.OnBossDefeated += () => Console.WriteLine("Achievement: Unlocked 'Giant Slayer'");
```

---

## 3. State (Состояние)
**Суть:** Позволяет объекту менять поведение в зависимости от внутреннего состояния. Похож на "умный switch".
**Где использовать:** AI персонажа (Idle, Run, Jump, Attack), состояния игры (Menu, Playing, Paused).

```csharp
public interface IState { void Handle(Player p); }

public class IdleState : IState
{
    public void Handle(Player p) 
    {
        if (p.IsMoving) p.SetState(new RunState());
    }
}

public class RunState : IState { /* логика бега */ }

public class Player
{
    private IState _state = new IdleState();
    public bool IsMoving { get; set; }
    public void SetState(IState s) => _state = s;
    public void Update() => _state.Handle(this);
}
```

## 5. Резюме
*   **Strategy**: Меняем алгоритм "на лету".
*   **Observer**: Рассылаем уведомления всем заинтересованным.
*   **State**: Меняем поведение объекта целиком в зависимости от ситуации.
