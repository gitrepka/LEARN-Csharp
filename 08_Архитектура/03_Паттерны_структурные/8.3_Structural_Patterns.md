# 8.3. Структурные паттерны (Structural Patterns)

## Введение
Структурные паттерны отвечают за то, как классы и объекты собираются в более крупные структуры.

---

## 1. Adapter (Адаптер)
**Суть:** Позволяет объектам с несовместимыми интерфейсами работать вместе. Это как переходник для розетки.
**Где использовать:** Когда у тебя есть старая библиотека или нативный API, который не подходит под твои интерфейсы.

```csharp
// То, что мы хотим использовать
public interface ITarget { string GetRequest(); }

// То, что у нас есть (несовместимое)
public class Adaptee { public string GetSpecificRequest() => "Specific text"; }

// Адаптер делает связь
public class Adapter : ITarget
{
    private readonly Adaptee _adaptee;
    public Adapter(Adaptee adaptee) => _adaptee = adaptee;

    public string GetRequest() => $"This is transformed: {_adaptee.GetSpecificRequest()}";
}
```

---

## 2. Decorator (Декоратор)
**Суть:** Позволяет динамически добавлять объектам новую функциональность, оборачивая их в "обертки".
**Где использовать:** Система баффов в игре, шифрование потоков данных (Streams).

```csharp
public interface IWeapon { int GetDamage(); }
public class Sword : IWeapon { public int GetDamage() => 10; }

// Базовый декоратор
public abstract class WeaponDecorator : IWeapon
{
    protected IWeapon _decoratedWeapon;
    public WeaponDecorator(IWeapon weapon) => _decoratedWeapon = weapon;
    public virtual int GetDamage() => _decoratedWeapon.GetDamage();
}

// Конкретный декоратор: Огненный урон
public class FireDecorator : WeaponDecorator
{
    public FireDecorator(IWeapon weapon) : base(weapon) { }
    public override int GetDamage() => base.GetDamage() + 5; // +5 урона огнем
}
```

## 3. Facade (Фасад)
**Суть:** Предоставляет простой интерфейс к сложной системе классов (скрывает сложность).
**Где использовать:** `SaveSystem`, которая внутри работает с JSON, FileStream и шифрованием, а снаружи дает только один метод `Save()`.

```csharp
public class InventorySystem { /* сложная логика */ }
public class QuestSystem { /* сложная логика */ }

public class GameSaveFacade
{
    private InventorySystem _inv = new();
    private QuestSystem _quests = new();

    public void SaveAll()
    {
        // Скрываем детали реализации от пользователя
        Console.WriteLine("Saving inventory...");
        Console.WriteLine("Saving quests...");
    }
}
```

## 5. Резюме
*   **Adapter**: Соединяет несовместимое.
*   **Decorator**: Расширяет функционал без наследования (слоями).
*   **Facade**: Прячет сложность за простой кнопкой.
