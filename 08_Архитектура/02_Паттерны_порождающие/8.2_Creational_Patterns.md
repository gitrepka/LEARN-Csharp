# 8.2. Порождающие паттерны (Creational Patterns)

## Введение
Порождающие паттерны отвечают за способы создания объектов. Они делают процесс создания более гибким и независимым от основной логики.

---

## 1. Singleton (Одиночка)
**Суть:** Гарантирует, что у класса есть только один экземпляр, и предоставляет к нему глобальную точку доступа.
**Где использовать:** `GameManager`, `AudioManager`, `SettingsService`.

```csharp
public sealed class GameManager
{
    private static GameManager _instance;
    private static readonly object _lock = new object();

    // Приватный конструктор — нельзя создать через new
    private GameManager() { }

    public static GameManager Instance
    {
        get
        {
            // Thread-safe реализация
            lock (_lock)
            {
                return _instance ??= new GameManager();
            }
        }
    }

    public int Score { get; set; }
}
```

---

## 2. Factory Method (Фабричный метод)
**Суть:** Определяет интерфейс для создания объекта, но позволяет наследникам решать, какой класс инстанцировать.
**Где использовать:** Спавн разных типов врагов или NPC.

```csharp
public abstract class Enemy { public abstract void Attack(); }
public class Ghost : Enemy { public override void Attack() => Console.WriteLine("Ghost scares!"); }
public class Orc : Enemy { public override void Attack() => Console.WriteLine("Orc smashes!"); }

public abstract class Spawner
{
    public abstract Enemy CreateEnemy(); // Тот самый фабричный метод
}

public class GhostSpawner : Spawner { public override Enemy CreateEnemy() => new Ghost(); }
public class OrcSpawner : Spawner { public override Enemy CreateEnemy() => new Orc(); }
```

---

## 3. Builder (Строитель)
**Суть:** Позволяет создавать сложные объекты пошагово.
**Где использовать:** Создание персонажа, конфигурация HTTP-запроса, сложные UI-элементы.

```csharp
public class Character
{
    public string Name { get; set; }
    public string Weapon { get; set; }
    public string Armor { get; set; }
}

public class CharacterBuilder
{
    private Character _char = new();

    public CharacterBuilder WithName(string name) { _char.Name = name; return this; }
    public CharacterBuilder WithSword() { _char.Weapon = "Sword"; return this; }
    public CharacterBuilder WithHeavyArmor() { _char.Armor = "Plate"; return this; }
    public Character Build() => _char;
}

// Использование (Fluent API):
var hero = new CharacterBuilder()
    .WithName("Arthas")
    .WithSword()
    .WithHeavyArmor()
    .Build();
```

## 5. Резюме
*   **Singleton**: Когда нужен строго один объект.
*   **Factory**: Когда нужно делегировать создание объекта.
*   **Builder**: Когда объект слишком сложный и его нужно собирать по частям.
