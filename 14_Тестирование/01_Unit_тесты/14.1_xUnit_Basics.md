# 14.1. Unit-тесты: xUnit

Тесты — это код, который проверяет другой код.
Ты не запускаешь программу руками и не тыкаешь кнопки. Ты запускаешь тесты, и они сами говорят: "Всё работает" или "Ты сломал калькулятор".

---

## 1. Фреймворк xUnit
В .NET это стандарт. Тесты живут в **отдельном проекте** (обычно `MyProject.Tests`).

## 2. Простой тест [Fact]

```csharp
public class CalculatorTests
{
    [Fact]
    public void Sum_ShouldReturnCorrectResult()
    {
        // Arrange (Подготовка)
        var calc = new Calculator();
        
        // Act (Действие)
        int result = calc.Add(2, 3);
        
        // Assert (Проверка)
        Assert.Equal(5, result);
    }
}
```

---

## 3. Параметризованный тест [Theory]
Чтобы не писать 100 тестов для разных чисел.

```csharp
[Theory]
[InlineData(1, 1, 2)]
[InlineData(5, 5, 10)]
[InlineData(-1, 1, 0)]
public void Add_Works(int a, int b, int expected)
{
    var calc = new Calculator();
    Assert.Equal(expected, calc.Add(a, b));
}
```

---

## 4. Практика
1. Создай класс `User` с методом `SetAge(int age)`. Метод должен бросать ошибку, если возраст < 0.
2. Напиши тест, который проверяет, что ошибка реально бросается (`Assert.Throws`).

---

## 5. Резюме
*   Тесты экономят время (не надо проверять руками).
*   `[Fact]` — один случай.
*   `[Theory]` — много случаев.
*   `Assert` — главный класс проверки.
