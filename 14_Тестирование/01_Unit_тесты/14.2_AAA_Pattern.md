# 14.2. Паттерн AAA

Чтобы тесты были читаемыми, они должны следовать структуре **AAA**.

---

## 1. Arrange (Подготовка)
Здесь мы создаем объекты, настраиваем данные.
```csharp
var hero = new Hero();
var sword = new Weapon(damage: 10);
```

## 2. Act (Действие)
Здесь мы вызываем **один** метод, который хотим проверить.
```csharp
hero.Equip(sword);
```

## 3. Assert (Проверка)
Здесь мы проверяем результат.
```csharp
Assert.Equal(sword, hero.CurrentWeapon);
Assert.Equal(10, hero.AttackPower);
```

---

## 4. Что нельзя делать в тестах
1.  Никакой логики (`if`, `for`). Тест должен быть прямым как рельса.
2.  Никаких случайных чисел (`Random`). Тест должен быть повторяемым.
3.  Никаких внешних зависимостей (Интернет, БД). Для этого нужны Моки (Mock), о которых мы поговорим позже.

---

## 5. Практика
Напиши тест для метода `GetDiscountPrice(price)`.
*   Arrange: Создай товар с ценой 100.
*   Act: Запроси цену со скидкой 20%.
*   Assert: Проверь, что результат равен 80.

---

## 6. Резюме
AAA — это стандарт чистоты теста. Соблюдай его, и твои тесты будут понятны любому.
