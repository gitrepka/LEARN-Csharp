# 1.1. Generics: Магия <T>

Обобщения (Generics) позволяют писать код, который работает с **любыми** типами данных, сохраняя при этом строгую проверку и высокую скорость.

---

## 1. Зачем это нужно?

Представь, что тебе нужен класс "Коробка" (`Box`).
Если ты сделаешь `int Box`, туда не влезет строка.
Если ты сделаешь `object Box`, тебе придется постоянно делать кастинг `(int)box.Value`, что медленно и опасно (можно ошибиться типом).

**Решение — Generics:**

```csharp
class Box<T> // T - это "заполнитель" для типа
{
    public T Content { get; set; }
}

// Использование:
var intBox = new Box<int> { Content = 123 };
var strBox = new Box<string> { Content = "Hello" };
```

---

## 2. Преимущества
1. **Type Safety (Безопасность):** Ты не сможешь положить число в `Box<string>`. Компилятор поймает ошибку сразу.
2. **Performance (Скорость):** Нет "упаковки" (boxing) значимых типов в `object`. Код работает так же быстро, как если бы ты написал его под конкретный тип.
3. **DRY:** Один код для всех типов.

---

## 3. Обобщенные методы

Метод тоже может быть "джанериком".

```csharp
public void Swap<T>(ref T a, ref T b)
{
    T temp = a;
    a = b;
    b = temp;
}
```

---

## 5. Резюме
*   `<T>` — это обещание: "Я подставлю тип позже".
*   Generics делают код гибким и быстрым.
*   Используются везде: во всех коллекциях C#.
