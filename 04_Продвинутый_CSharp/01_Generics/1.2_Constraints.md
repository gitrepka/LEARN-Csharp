# 1.2. Ограничения Generics: where T : ...

Иногда просто `<T>` — это слишком свободно. Что если внутри класса ты хочешь вызвать метод `Calculate()`, но не у всех типов он есть? 
Нужно ограничить выбор типов.

---

## 1. Синтаксис where

```csharp
class Repository<T> where T : class // T обязан быть ссылочным типом
{
    public void Save(T item) { ... }
}
```

## 2. Основные ограничения

*   `where T : struct` — только значимые типы (`int`, `bool`, `struct`).
*   `where T : class` — только ссылочные типы.
*   `where T : new()` — у типа ОБЯЗАТЕЛЬНО должен быть конструктор без параметров. (Это позволит тебе написать `T item = new T();`).
*   `where T : MyBaseClass` — только этот класс или его наследники.
*   `where T : IMyInterface` — тип обязан реализовывать этот интерфейс.

---

## 3. Комбинирование

Можно указывать несколько ограничений:
```csharp
class MyClass<T> where T : class, ICloneable, new()
{
    // T - это класс, имеющий пустой конструктор и умеющий клонироваться.
}
```

---

## 4. Практика: Универсальный склад

### Задание 1.2.1
Создай интерфейс `IEntity` с полем `int Id`.
Создай класс `Database<T> where T : IEntity`.
1. Добавь метод `FindById(List<T> items, int id)`.
2. Благодаря ограничению, внутри метода ты сможешь обращаться к `item.Id`.

---

## 5. Резюме
*   `where` — сужает круг типов.
*   Это позволяет использовать методы и свойства внутри обобщенного кода.
*   `new()` — самое частое ограничение для создания объектов внутри.
