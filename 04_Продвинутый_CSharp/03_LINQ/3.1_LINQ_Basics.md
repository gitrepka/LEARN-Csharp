# 3.1. LINQ: Запросы в одну строку

LINQ (Language Integrated Query) — это способ работать с коллекциями как с базами данных. Забудь про бесконечные циклы `foreach` с условиями внутри.

---

## 1. Пример Магии

**Задача:** Из списка чисел выбрать только четные, больше 10, и отсортировать их.

**Без LINQ:**
```csharp
var result = new List<int>();
foreach (var n in numbers)
{
    if (n % 2 == 0 && n > 10) result.Add(n);
}
result.Sort();
```

**С LINQ:**
```csharp
using System.Linq;

var result = numbers
    .Where(n => n % 2 == 0 && n > 10)
    .OrderBy(n => n)
    .ToList();
```

---

## 2. Основные методы

*   `Where` — фильтрация (условие).
*   `Select` — преобразование (например, из списка объектов в список их имен).
*   `OrderBy` / `OrderByDescending` — сортировка.
*   `First` / `FirstOrDefault` — взять первый элемент.
*   `Any` — есть ли хоть один элемент, подходящий под условие? (Возвращает bool).
*   `Count` — посчитать количество.

---

## 3. Отложенное выполнение (Важно!)

LINQ не выполняет запрос сразу. Он "запоминает" его. Запрос сработает только тогда, когда ты начнешь перебирать результат (через `foreach` или `.ToList()`).

---

## 5. Резюме
*   LINQ делает код короче и понятнее.
*   Всегда возвращает новую коллекцию, не меняя старую.
*   Подключается через `using System.Linq;`.
