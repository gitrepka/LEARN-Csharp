# 2.1. Делегаты: Методы как переменные

Делегат — это тип, который представляет ссылку на метод. Это позволяет передавать один метод внутрь другого метода.

---

## 1. Зачем это нужно? (Аналогия)
Представь кнопку. Кнопка не знает, что она должна делать при нажатии. Она просто говорит: "Я нажат!". Ты даешь ей метод (делегат), который она должна запустить.

---

## 2. Современные делегаты: Action и Func

Тебе не нужно объявлять свои делегаты, в C# уже есть готовые:

*   **Action<...>** — для методов, которые возвращают `void`.
*   **Func<..., TResult>** — для методов, которые **возвращают** значение. (Последний тип в списке — это тип возврата).

```csharp
// Action (принимает string, ничего не возвращает)
Action<string> print = (message) => Console.WriteLine(message);
print("Hello!");

// Func (принимает два int, возвращает int)
Func<int, int, int> add = (a, b) => a + b;
int result = add(5, 10);
```

---

## 3. Лямбда-выражения (`=>`)
Это короткий способ написать анонимный метод.
` (параметры) => { тело_метода } `

---

## 4. Практика: Универсальный фильтр

### Задание 2.1.1
Напиши метод `static List<int> Filter(List<int> numbers, Func<int, bool> predicate)`.
* Он должен возвращать новый список только с теми числами, которые подходят под условие (предикат).
* Вызови его, передав лямбду для поиска четных чисел.
* Вызови его, передав лямбду для поиска чисел больше 10.

---

## 5. Резюме
*   Делегат — переменная для метода.
*   `Action` — без возврата.
*   `Func` — с возвратом.
*   Лямбды `=>` делают код очень коротким.
