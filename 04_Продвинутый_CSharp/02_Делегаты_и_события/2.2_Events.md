# 2.2. События: Подписка и Уведомления

События (`event`) — это безопасная обертка над делегатами. Они позволяют одному объекту (Издателю) уведомлять другие объекты (Подписчиков) о том, что что-то произошло.

---

## 1. Зачем нужны события? (Слабая связность)

Объект `Player` не должен знать, что при его смерти нужно:
1. Показать надпись "Game Over" в UI.
2. Проиграть грустную музыку.
3. Отправить статистику на сервер.

Игрок просто кричит: **"Я умер!"**. А все остальные службы (UI, Sound, Network) подписываются на этот крик.

---

## 2. Использование

```csharp
class Player
{
    // Объявление события
    public event Action OnDeath;

    public void Die()
    {
        Console.WriteLine("Игрок погиб...");
        // Вызываем событие (уведомляем всех подписчиков)
        OnDeath?.Invoke(); 
    }
}

// В другом месте кода (Подписка):
player.OnDeath += ShowUIMessage;
player.OnDeath += PlaySound;

// Отписка (Важно для памяти!):
player.OnDeath -= PlaySound;
```

---

## 3. Разница между делегатом и событием
*   Делегат можно вызвать откуда угодно.
*   Событие может вызвать **ТОЛЬКО** тот класс, который его объявил. Все остальные могут только подписываться или отписываться. Это безопасность.

---

## 5. Резюме
*   События — основа UI и игровых движков.
*   `+=` — подписаться, `-=` — отписаться.
*   Используй `?.Invoke()`, чтобы не упасть, если на событие никто не подписан.
