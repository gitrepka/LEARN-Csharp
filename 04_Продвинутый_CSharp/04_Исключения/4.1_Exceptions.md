# 4.1. Исключения: Когда всё идет не так

Исключение (Exception) — это событие, которое прерывает нормальный ход программы (например, деление на ноль или попытка прочитать несуществующий файл).

---

## 1. Обработка ошибок (try-catch)

Чтобы программа не "вылетала", мы оборачиваем опасный код в блок `try`.

```csharp
try
{
    int x = int.Parse(Console.ReadLine());
    Console.WriteLine(10 / x);
}
catch (DivideByZeroException)
{
    Console.WriteLine("На ноль делить нельзя!");
}
catch (FormatException)
{
    Console.WriteLine("Нужно ввести именно число!");
}
catch (Exception ex) // Поймает любую другую ошибку
{
    Console.WriteLine($"Что-то пошло не так: {ex.Message}");
}
finally
{
    // Этот код выполнится ВСЕГДА (была ошибка или нет)
    // Удобно для закрытия файлов или соединений с БД.
    Console.WriteLine("Завершение операции.");
}
```

---

## 2. Ключевое слово throw

Ты можешь сам "бросить" исключение, если что-то идет не по плану.

```csharp
public void SetAge(int age)
{
    if (age < 0)
        throw new ArgumentException("Возраст не может быть отрицательным!");
    _age = age;
}
```

---

## 4. Резюме
*   `try` — пробуем.
*   `catch` — спасаем ситуацию.
*   `finally` — прибираемся за собой.
*   Используй конкретные типы ошибок (`DivideByZeroException`), а не общий `Exception`, где это возможно.
