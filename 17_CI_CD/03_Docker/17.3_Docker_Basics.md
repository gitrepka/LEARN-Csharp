# 17.3. Docker: Код в коробке

"У меня всё работает, а на сервере падает". Docker решает эту проблему.
Он упаковывает твой код вместе с Linux, библиотеками и настройками в один файл — **Образ (Image)**.

---

## 1. Dockerfile
Это рецепт приготовления образа.

```dockerfile
# Берем официальный .NET (SDK)
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /app

# Копируем код и собираем
COPY . .
RUN dotnet publish -c Release -o out

# Запускаем
FROM mcr.microsoft.com/dotnet/aspnet:8.0
WORKDIR /app
COPY --from=build /app/out .
ENTRYPOINT ["dotnet", "MyServer.dll"]
```

Теперь твой сервер можно запустить одной командой на любом компьютере в мире.
