# 17.2. GitHub Actions: Современный CI/CD для .NET 10

Автоматизация сборки и тестирования (CI) — это стандарт индустрии. GitHub Actions позволяет бесплатно запускать твой код в облаке на Windows, Linux и macOS.

---

## 1. Конфигурация для .NET 10

Файлы рабочих процессов (workflows) хранятся в `.github/workflows/`.

```yaml
# .github/workflows/main.yml
name: CI/CD Pipeline

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    
    steps:
    - name: Checkout code
      uses: actions/checkout@v4

    - name: Setup .NET 10
      uses: actions/setup-dotnet@v4
      with:
        dotnet-version: '10.0.x'
        
    - name: Restore dependencies
      run: dotnet restore
      
    # Кэширование пакетов ускоряет сборку в 2-3 раза
    - name: Cache NuGet packages
      uses: actions/cache@v4
      with:
        path: ~/.nuget/packages
        key: ${{ runner.os }}-nuget-${{ hashFiles('**/*.csproj') }}
        restore-keys: |
          ${{ runner.os }}-nuget-

    - name: Build
      run: dotnet build --configuration Release --no-restore

    - name: Run Tests
      run: dotnet test --no-build --verbosity normal
```

## 2. Специфика Godot в CI/CD

Для сборки игр в Godot нужны дополнительные шаги: установка самого движка и экспортных шаблонов.

```yaml
  export-godot:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup .NET 10
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '10.0.x'
      - name: Export Game
        uses: firebelley/godot-export@v5.2.1
        with:
          godot_executable_download_url: https://downloads.tuxfamily.org/godotengine/4.6/Godot_v4.6-stable_mono_linux_x86_64.zip
          godot_export_templates_download_url: https://downloads.tuxfamily.org/godotengine/4.6/Godot_v4.6-stable_mono_export_templates.tpz
          relative_project_path: ./MyGodotGame
          archive_output: true
```

## 3. Специфика Uno Platform

Uno требует сборки под разные платформы. Для Windows нужен `windows-latest`, для iOS/macOS — `macos-latest`.

```yaml
  build-wasm:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-dotnet@v4
      - name: Install Uno Templates
        run: dotnet new install Uno.Templates
      - name: Build WASM
        run: dotnet publish -c Release MyUnoApp.Wasm.csproj
```

## 4. Секреты (Secrets)

Никогда не храни пароли или ключи подписи в YAML! Используй **GitHub Secrets**.
`Settings -> Secrets and variables -> Actions`.

```yaml
    - name: Deploy to Server
      run: ./deploy.sh
      env:
        SSH_KEY: ${{ secrets.MY_SERVER_SSH_KEY }}
```

## 5. Практика: Твой первый Pipeline

### Задание 17.2.1
1. Создай репозиторий на GitHub.
2. Добавь в него простой консольный проект с одним xUnit тестом.
3. Настрой `.github/workflows/ci.yml`, чтобы он запускал тесты при каждом пуше.
4. Намеренно сломай тест, запушь и убедись, что GitHub прислал уведомление об ошибке (Red Build). Исправь и добейся "зеленого" статуса.

## 6. Резюме
*   **Actions** — автоматизация всего: от тестов до деплоя.
*   **Caching** — экономит время и деньги (минуты сборки).
*   **Matrices** — позволяют тестировать код сразу на всех ОС.
*   **Secrets** — единственный способ безопасного хранения ключей.
