# 17.1. Git Flow: Как работают в командах

Ты уже знаешь `git commit`. Но в команде нельзя просто пушить в `main`.

---

## 1. Ветки (Branches)
*   `main` — священный код. То, что сейчас работает у пользователей.
*   `develop` — черновик следующей версии.
*   `feature/new-gun` — твоя личная ветка, где ты делаешь новую пушку.

---

## 2. Pull Request (PR)
Когда ты закончил фичу, ты не сливаешь её сам. Ты создаешь **PR**.
Твой коллега (или ментор) читает код, пишет замечания ("исправь отступы") и только потом нажимает **Merge**.

---

## 3. Практика
1. Создай ветку `feature/test`.
2. Измени файл.
3. Запушь.
4. Создай Pull Request на GitHub.
