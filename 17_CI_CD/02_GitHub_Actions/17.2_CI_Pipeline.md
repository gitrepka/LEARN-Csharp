# 17.2. GitHub Actions: Твой личный робот

CI (Continuous Integration) — это когда сервер сам проверяет твой код.

---

## 1. Как это работает?
Ты создаешь файл `.github/workflows/dotnet.yml`. Это инструкция для робота GitHub.

```yaml
name: .NET Build

on: [push] # Делать это при каждом пуше

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    - name: Setup .NET
      uses: actions/setup-dotnet@v3
      with:
        dotnet-version: 8.0.x
    - name: Build
      run: dotnet build
    - name: Test
      run: dotnet test
```

Теперь, если ты сломаешь код и запушишь его, GitHub пришлет тебе письмо: "Сборка упала!". Это спасает от багов.
