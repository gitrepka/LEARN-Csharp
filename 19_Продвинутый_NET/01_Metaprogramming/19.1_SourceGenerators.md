# 19.1. Source Generators: Метапрограммирование

Рефлексия (Reflection) — это медленно, потому что она изучает код во время работы.
Source Generators работают **во время компиляции**. Они анализируют твой код и дописывают к нему новые файлы.

---

## 1. Идея
Ты пишешь:
```csharp
[AutoNotify]
private int _score;
```

Генератор видит это и создает файл `Hero.g.cs`:
```csharp
partial class Hero
{
    public int Score
    {
        get => _score;
        set 
        {
            _score = value;
            OnPropertyChanged("Score");
        }
    }
}
```
Это происходит мгновенно. Ты получаешь магию без потери производительности.
