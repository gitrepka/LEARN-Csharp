# 19.4. Сжатие данных: Zip, GZip, Brotli

## Введение
В .NET работа со сжатием встроена в пространство имен `System.IO.Compression`. Мы можем легко создавать ZIP-архивы, распаковывать их, а также сжимать потоки данных "на лету" с помощью GZip или более современного Brotli.

---

## 1. Работа с ZIP-архивами

Самый простой способ работы с архивами — статический класс `ZipFile`. Он идеально подходит, когда нужно просто "запаковать папку" или "распаковать файл".

### Создание и распаковка

```csharp
using System.IO.Compression;

string startPath = @".\data";
string zipPath = @".\result.zip";
string extractPath = @".\extracted";

// Создать архив из папки
ZipFile.CreateFromDirectory(startPath, zipPath);

// Распаковать архив в папку
ZipFile.ExtractToDirectory(zipPath, extractPath);
```

### Работа с содержимым архива
Если нужно добавить один файл в существующий архив или прочитать список файлов без полной распаковки, используем `ZipArchive`.

```csharp
using FileStream zipToOpen = new FileStream("archive.zip", FileMode.Open);
using ZipArchive archive = new ZipArchive(zipToOpen, ZipArchiveMode.Update);

// Создать запись (файл внутри архива)
ZipArchiveEntry readmeEntry = archive.CreateEntry("Readme.txt");
using StreamWriter writer = new StreamWriter(readmeEntry.Open());
writer.WriteLine("Information about this package.");

// Прочитать записи
foreach (ZipArchiveEntry entry in archive.Entries)
{
    Console.WriteLine(entry.FullName);
}
```

## 2. Потоковое сжатие: GZip, Deflate, Brotli

Для сжатия данных в оперативной памяти или при передаче по сети (например, в HTTP) используются классы-наследники `Stream`. Они работают как "обертки" над другими потоками.

### GZipStream
Стандарт де-факто для сжатия файлов и веб-трафика.

```csharp
// Сжатие
using FileStream originalFile = File.OpenRead("data.txt");
using FileStream compressedFile = File.Create("data.txt.gz");
using GZipStream compressor = new GZipStream(compressedFile, CompressionMode.Compress);

originalFile.CopyTo(compressor); // Данные текут из файла через компрессор в новый файл

// Распаковка
using FileStream compressed = File.OpenRead("data.txt.gz");
using FileStream decompressed = File.Create("data_restored.txt");
using GZipStream decompressor = new GZipStream(compressed, CompressionMode.Decompress);

decompressor.CopyTo(decompressed);
```

### BrotliStream
Более современный алгоритм (от Google), обеспечивающий лучшее сжатие, чем GZip, при схожей скорости распаковки. Активно используется в вебе.

```csharp
using var outputStream = new MemoryStream();
using var brotli = new BrotliStream(outputStream, CompressionLevel.Optimal);

byte[] data = System.Text.Encoding.UTF8.GetBytes("Huge amount of text...");
brotli.Write(data, 0, data.Length);
```

*Совет:* Используй `CompressionLevel.Optimal` для баланса или `SmallestSize` для максимального сжатия (но медленнее). `Fastest` — если важна скорость (например, в играх).

## 3. Практика: Архиватор логов

### Задание 19.4.1
Напиши утилиту, которая:
1. Создает текстовый файл "log.txt" и заполняет его 10 000 строками "Log entry #N".
2. Сжимает этот файл в "log.gz" используя `GZipStream`.
3. Сжимает этот же файл в "log.br" используя `BrotliStream`.
4. Сравнивает размеры полученных файлов и выводит победителя.

---

## 4. Резюме
*   `ZipFile` — для работы с `.zip` архивами (файловая система).
*   `GZipStream` — классика потокового сжатия.
*   `BrotliStream` — современный и эффективный выбор для текста и веба.
