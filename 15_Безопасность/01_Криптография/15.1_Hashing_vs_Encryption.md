# 15.1. Хеширование vs Шифрование

Новички часто путают эти понятия. Ошибка здесь стоит очень дорого (утечка данных пользователей).

---

## 1. Шифрование (Encryption) — AES, RSA
Это процесс **обратимый**. 
*   У тебя есть ключ (пароль).
*   Ты закрываешь данные в сейф (зашифровал).
*   Ты можешь открыть сейф ключом (расшифровал).

**Для чего:** Хранение личных переписок, данных кредиток, сохранений игры (чтобы не читерили).

```csharp
// (Псевдокод)
byte[] encrypted = Aes.Encrypt(data, key);
byte[] original = Aes.Decrypt(encrypted, key);
```

---

## 2. Хеширование (Hashing) — SHA256
Это процесс **необратимый**.
*   Ты превращаешь данные в уникальную строку символов (хеш).
*   Вернуть из хеша исходные данные **невозможно** (фарш нельзя провернуть назад).

**Для чего:** Хранение паролей.
Если ты забыл пароль, сервис не может его "напомнить" (он его не знает!), он может только сбросить его.

---

## 3. Практика: Хеш файла
Хеши часто используют для проверки целостности файлов (не побился ли файл при скачивании).

```csharp
using System.Security.Cryptography;
using System.Text;

string text = "Hello World";
byte[] bytes = Encoding.UTF8.GetBytes(text);
byte[] hash = SHA256.HashData(bytes);

Console.WriteLine(Convert.ToHexString(hash));
```

---

## 4. Резюме
*   Нужно вернуть данные? -> Шифрование.
*   Нужно только проверить совпадение? -> Хеширование.
