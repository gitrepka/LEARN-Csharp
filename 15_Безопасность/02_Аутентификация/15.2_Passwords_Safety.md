# 15.2. Аутентификация: JWT и Современные стандарты

Когда твое приложение (Uno) общается с сервером (ASP.NET Core), сервер должен знать, кто к нему обращается. Передавать логин и пароль при каждом запросе — небезопасно. Для этого используют **JWT (JSON Web Token)**.

---

## 1. Что такое JWT?

JWT — это строка, которая содержит информацию о пользователе (его ID, имя, права) и **цифровую подпись**.
**Суть:** Сервер подписывает токен секретным ключом. Если хакер изменит хотя бы одну букву в токене (например, изменит роль с "User" на "Admin"), подпись станет невалидной, и сервер отвергнет запрос.

### Структура JWT:
1.  **Header**: Алгоритм подписи.
2.  **Payload**: Данные (Claims) — ID пользователя, срок действия (exp).
3.  **Signature**: Результат хеширования Header + Payload с твоим секретным ключом.

---

## 2. Реализация в ASP.NET Core

Для работы с JWT на сервере используется пакет `Microsoft.AspNetCore.Authentication.JwtBearer`.

```csharp
// Program.cs
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            ValidIssuer = "my-auth-server",
            ValidAudience = "my-uno-app",
            IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes("SuperSecretKey123!"))
        };
    });

// Использование в контроллере
[Authorize(Roles = "Admin")]
[HttpGet("secret-data")]
public IActionResult GetSecret() => Ok("Only admins see this!");
```

## 3. Безопасное хранение на клиенте (Uno/Godot)

**Главная ошибка:** Хранить токен в обычном файле или `LocalStorage` в открытом виде.
*   **WASM (Браузер)**: Используй `HttpOnly` Cookies (если сервер и клиент на одном домене).
*   **Мобильные / Десктоп**: Используй нативные защищенные хранилища (SecureStorage в Uno, Keychain в iOS).

```csharp
// Пример Uno Platform (Community Toolkit)
await SecureStorage.Default.SetAsync("auth_token", jwtToken);
string token = await SecureStorage.Default.GetAsync("auth_token");
```

## 4. OAuth 2.0 и OpenID Connect (OIDC)

Вместо того чтобы писать свою систему регистрации, лучше использовать гигантов (Google, GitHub, Microsoft).
*   **OAuth 2.0**: Процесс получения прав доступа ("Разрешить приложению доступ к моим фото").
*   **OIDC**: Процесс идентификации ("Кто я?").

В .NET для этого идеально подходит библиотека **Duende IdentityServer** или облачные решения (Azure AD, Auth0).

## 6. Резюме
*   **JWT**: Легкий и надежный способ передать права доступа.
*   **Claims**: Информация внутри токена.
*   **Authorization**: Проверка прав (что пользователю разрешено).
*   **Authentication**: Проверка личности (кто этот пользователь).
