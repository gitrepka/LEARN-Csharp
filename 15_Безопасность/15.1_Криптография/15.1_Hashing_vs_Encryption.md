# 15.1. Криптография в .NET: Хеширование и Шифрование

Безопасность — это не только защита от хакеров, но и защита данных пользователя от случайной утечки. В .NET основные инструменты собраны в `System.Security.Cryptography`.

---

## 1. Хеширование: Необратимая проверка

Хеширование превращает данные в строку фиксированной длины. 
**Главное правило:** Пароли в базе данных должны храниться ТОЛЬКО в виде хешей.

### Проблема радужных таблиц
Если два пользователя выберут пароль `12345`, их хеши будут одинаковыми. Хакеры используют "радужные таблицы" (базы заранее вычисленных хешей), чтобы мгновенно взломать такие пароли.

### Решение: Соль (Salt)
Мы добавляем к паролю случайную строку (соль) перед хешированием. Теперь даже одинаковые пароли будут иметь разные хеши.

```csharp
using System.Security.Cryptography;
using System.Text;

public static class HashHelper
{
    private const int SaltSize = 16; // 128 bit
    private const int KeySize = 32;  // 256 bit
    private const int Iterations = 100000; // замедляем брутфорс

    public static string HashPassword(string password, out byte[] salt)
    {
        salt = RandomNumberGenerator.GetBytes(SaltSize);
        var hash = Rfc2898DeriveBytes.Pbkdf2(
            Encoding.UTF8.GetBytes(password),
            salt,
            Iterations,
            HashAlgorithmName.SHA256,
            KeySize);

        return Convert.ToHexString(hash);
    }

    public static bool VerifyPassword(string password, string hash, byte[] salt)
    {
        var hashToVerify = Rfc2898DeriveBytes.Pbkdf2(
            password,
            salt,
            Iterations,
            HashAlgorithmName.SHA256,
            KeySize);
        
        return CryptographicOperations.FixedTimeEquals(hashToVerify, Convert.FromHexString(hash));
    }
}
```

## 2. Шифрование: Обратимая защита (AES)

AES (Advanced Encryption Standard) — это симметричное шифрование (один ключ для закрытия и открытия). Используется для защиты файлов, сохранений и личных данных.

```csharp
public static class AesHelper
{
    public static byte[] Encrypt(string plainText, byte[] key, out byte[] iv)
    {
        using Aes aes = Aes.Create();
        aes.Key = key;
        iv = aes.IV; // Вектор инициализации (нужен для дешифровки)

        using var encryptor = aes.CreateEncryptor();
        byte[] inputBytes = Encoding.UTF8.GetBytes(plainText);
        return encryptor.TransformFinalBlock(inputBytes, 0, inputBytes.Length);
    }

    public static string Decrypt(byte[] cipherText, byte[] key, byte[] iv)
    {
        using Aes aes = Aes.Create();
        aes.Key = key;
        aes.IV = iv;

        using var decryptor = aes.CreateDecryptor();
        byte[] resultBytes = decryptor.TransformFinalBlock(cipherText, 0, cipherText.Length);
        return Encoding.UTF8.GetString(resultBytes);
    }
}
```

## 4. Резюме
*   **Хеширование (Pbkdf2)**: Только для паролей. Всегда используй **Salt**.
*   **Шифрование (AES)**: Для данных, которые нужно вернуть в исходный вид. Всегда храни **IV** рядом с зашифрованными данными.
*   **Никогда** не пиши свои алгоритмы шифрования. Используй стандартные из .NET.
