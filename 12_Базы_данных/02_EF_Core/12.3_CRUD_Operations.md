# 12.3. CRUD: Основные операции

CRUD — это 4 столпа работы с данными:
*   **C**reate (Создать)
*   **R**ead (Прочитать)
*   **U**pdate (Обновить)
*   **D**elete (Удалить)

Все это делается через `DbContext`.

---

## 1. Create (Добавление)

```csharp
using var db = new GameContext();

var newPlayer = new Player { Name = "Alex", Score = 100 };
db.Players.Add(newPlayer); // Добавили в память
db.SaveChanges(); // ОТПРАВИЛИ В БАЗУ (Сохранили)
```

---

## 2. Read (Чтение и Поиск)
Здесь используется LINQ!

```csharp
// Получить всех
var all = db.Players.ToList();

// Найти конкретного
var alex = db.Players.FirstOrDefault(p => p.Name == "Alex");
```

---

## 3. Update (Обновление)

```csharp
var player = db.Players.First(p => p.Name == "Alex");
player.Score += 50; // Меняем обычное свойство C#
db.SaveChanges(); // EF Core видит изменения и сам делает UPDATE
```

---

## 4. Delete (Удаление)

```csharp
var player = db.Players.First(p => p.Name == "Alex");
db.Players.Remove(player);
db.SaveChanges();
```

---

## 5. Практика: Таблица рекордов
1. Напиши программу, которая спрашивает имя и очки.
2. Сохраняет их в БД.
3. Выводит Топ-5 игроков (используй `OrderByDescending` и `Take(5)`).

---

## 6. Резюме
*   `Add` + `SaveChanges` = Insert.
*   LINQ = Select.
*   Изменение свойства + `SaveChanges` = Update.
*   `Remove` + `SaveChanges` = Delete.
