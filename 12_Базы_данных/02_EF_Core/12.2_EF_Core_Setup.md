# 12.2. EF Core: Подход Code First

Entity Framework Core (EF Core) — это ORM (Object-Relational Mapper).
Это переводчик:
*   Ты даешь ему C# объекты.
*   Он превращает их в SQL-команды и сохраняет в БД.

---

## 1. Установка
Тебе понадобятся NuGet пакеты:
1. `Microsoft.EntityFrameworkCore.Sqlite`
2. `Microsoft.EntityFrameworkCore.Tools`

---

## 2. Создание Сущности (Entity)
Это обычный класс, но с полем `Id`.

```csharp
public class Player
{
    public int Id { get; set; } // EF Core поймет, что это Ключ
    public string Name { get; set; }
    public int Score { get; set; }
}
```

---

## 3. DbContext (Контекст базы данных)
Это главный класс, который управляет базой.

```csharp
using Microsoft.EntityFrameworkCore;

public class GameContext : DbContext
{
    // Таблица Игроков
    public DbSet<Player> Players { get; set; }

    // Настройка пути к файлу БД
    protected override void OnConfiguring(DbContextOptionsBuilder options)
        => options.UseSqlite("Data Source=game.db");
}
```

---

## 4. Практика: Первая БД
1. Создай консольный проект.
2. Подключи NuGet пакеты.
3. Создай классы `Player` и `GameContext`.
4. В `Main` напиши:
   ```csharp
   using var db = new GameContext();
   db.Database.EnsureCreated(); // Создает файл game.db, если его нет
   Console.WriteLine("База данных готова!");
   ```

---

## 5. Резюме
*   `Entity` — класс-данные.
*   `DbContext` — класс-управляющий.
*   `EnsureCreated` — быстрое создание БД для тестов.
