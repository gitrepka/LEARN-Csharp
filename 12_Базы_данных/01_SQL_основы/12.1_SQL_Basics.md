# 12.1. SQL и Реляционные Базы Данных

Прежде чем писать код, нужно понять, как хранятся данные.
База данных (БД) — это набор таблиц, связанных друг с другом.

---

## 1. Таблица и Колонки
Представь Excel-таблицу `Players`.
*   **Columns (Колонки):** Имя, Уровень, Здоровье. Это свойства класса.
*   **Rows (Строки):** Конкретные игроки (Alex, Bob). Это объекты.

## 2. Primary Key (PK) — Первичный ключ
У каждой строки должен быть **уникальный ID**.
Имена могут повторяться (два Алекса), а ID — никогда. По ID мы находим запись.

## 3. Связи (Relations)
У игрока есть Инвентарь. Мы не пишем все предметы в ячейку игрока.
Мы создаем таблицу `Items` и добавляем туда колонку `PlayerId`.
*   Это связь **Один-ко-Многим**: Один игрок — много предметов.

---

## 4. Язык SQL (Кратко)
Хотя мы будем использовать C#, полезно знать, что происходит "под капотом":
*   `SELECT * FROM Players` — дай всех игроков.
*   `INSERT INTO Players ...` — добавь игрока.
*   `UPDATE Players ...` — измени данные.
*   `DELETE FROM Players ...` — удали.

---

## 5. Резюме
*   БД хранит данные в таблицах.
*   У каждой записи есть уникальный `Id`.
*   Мы будем использовать **SQLite** — это база данных, которая хранится в одном файле `.db` и не требует установки сервера. Идеально для игр и приложений.
