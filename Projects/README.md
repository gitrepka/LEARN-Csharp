# Проекты-спутники

Два основных проекта, которые растут с каждым модулем обучения.

## RoguelikeSurvivor_Godot/
Godot 4.6 C# — рогалик, начинающийся с квадрата и вырастающий в полноценную игру.

## PersonalHub_Uno/
Uno Platform — персональное приложение, начинающееся с Hello World и вырастающее в полноценный инструмент.

> Эти проекты НЕ привязаны к одному модулю — они развиваются сквозь ВСЕ модули.
> Каждый модуль добавляет новую фичу в оба проекта.
